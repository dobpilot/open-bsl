# Нативное ненулевое условное разделение

Платформа 8.3.27.2342, собственная файловая база
`/tmp/open-bsl-common-attribute-condition-1009-ib`, создана только для замера.
`control.cf` и XML экспортированы read-only средствами Designer после
успешного `measure-common-attribute-metadata-condition.bsl`. Квитанция
сохранена рядом со скриптом как `.platform.txt` (14 строк).

У общего реквизита включено Separate, AutoUse=DontUse; явная запись
справочника с Use имеет условие Boolean-константы. Нативное условие
возвращает объект метаданных константы, идентичный корневой ссылке.
Полный состав включает также неявный каталог и саму константу с Auto/Undefined.
Этот контроль не доказывает общий порядок или применимость всех классов.
SHA256SUMS фиксирует восемь независимых артефактов выгрузки.

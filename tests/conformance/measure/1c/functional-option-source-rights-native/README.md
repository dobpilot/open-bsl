# Нативная граница привилегированного чтения опций справочника и регистра

1С 8.3.27.2342, собственная файловая база `/tmp/open-bsl-functional-option-source-rights-1009-ib`. Рабочие базы не менялись. Сначала `measure-functional-option-source-rights-setup.bsl` создаёт один элемент с булевым значением `Истина`, одну запись независимого непериодического регистра и пользователей FunctionalAdmin/FunctionalDenied. Затем `measure-functional-option-source-rights.bsl` выполняется отдельным тонким клиентом от FunctionalDenied. У него нет чтения обоих источников.

Обычные опции отказывают до и после привилегированных вызовов; привилегированные возвращают `Boolean:Yes`; `ПравоДоступа` остаётся `No`. Полный независимый ответ сохранён рядом со скриптом (21 физическая строка с продолжениями диагностик). Уведомление developer-license подтверждено только в визуально проверенном окне собственного PID.

`control.cf` и `xml/` выгружены штатными `/DumpCfg` и `/DumpConfigToFiles` после успешного замера. XML содержит корень, источники, параметры, опции и роли; вспомогательная форма находится в CF и воспроизводится runner-ом. Это конфигурационные артефакты, не выгрузка пользовательских данных. `SHA256SUMS` проверяет все сохранённые артефакты. RLS, разделение данных и общий кеш этим контролем не измерены.

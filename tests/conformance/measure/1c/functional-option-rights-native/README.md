# Нативные права функциональных опций

Платформа 1С 8.3.27.2342, отдельная файловая база
`/tmp/open-bsl-functional-option-rights-1009-ib`, 2026-10-09.
Инициализация `../measure-functional-option-rights-setup.bsl` записала True
в собственную константу и создала двух тестовых пользователей с пустыми
паролями и включённой стандартной аутентификацией. FunctionalAdmin имеет
полные права; FunctionalDenied — вход и доступ к обработке замеров,
без Read/View константы. Ни один пользователь рабочей базы не менялся.

Проба `../measure-functional-option-rights.bsl` выполнена тонким клиентом
под FunctionalDenied, Designer использовал FunctionalAdmin. Квитанция
проверяет имя текущего пользователя, Read до/после, прямое чтение,
непривилегированную опцию до/после и привилегированную опцию.
Сохранены 9 логических записей (11 физических строк: ошибки содержат
перевод строки). Прямое чтение и обычная опция отказывают, привилегированная
возвращает Boolean:Yes; право Read и отказ обычной опции не изменяются.

CF и XML выгружены штатными Designer /DumpCfg и /DumpConfigToFiles после
контроля. Девять файлов проверяются SHA256SUMS. Пользователи не входят
в CF-конфигурацию: для воспроизведения нужен отдельный setup-скрипт.
Нативный XML роли сохраняет setForNewObjects=false и
setForAttributesByDefault=false; явные false прав константы из входного
XML платформа опустила как значения по умолчанию. Входной XML не выдан
за нативную выгрузку.

Запуск:
1. Создать новую базу runner с measure-functional-option-rights-setup.bsl.
2. Повторить runner с measure-functional-option-rights.bsl в той же базе;
   через ONEC_PLATFORM передать обёртку 1cv8 с /NFunctionalAdmin,
   через ONEC_ENTERPRISE_PLATFORM — 1cv8c с /NFunctionalDenied.
3. Обёртка тонкого клиента должна допустить стартовые окна. На этом
   запуске показано информационное предупреждение лицензии разработчика;
   его снимок проверен, Return отправлен только после проверки PID по
   собственному 1Cv8.1CD и принадлежности фокуса окну этого процесса.

Использованные обёртки: /tmp/open-bsl-functional-option-admin-1009.sh,
/tmp/open-bsl-functional-option-denied-1009.sh. Они отклоняют любой путь
базы, кроме указанной выше. Логи: /tmp/open-bsl-functional-option-rights-1009.log
и /tmp/open-bsl-functional-option-rights-setup-1009.log.
Снимок только своего окна: /tmp/open-bsl-functional-option-rights-window-1009.png.

Это не измерение RLS, разделителей данных, привилегированного чтения
реквизита/ресурса, межсеансового кэша или переключения пользователя.
Контроль проверяет изоляцию проверок чтения в одном выбранном сеансе.

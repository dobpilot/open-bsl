# Нативный порядок состава общего реквизита

Платформа 8.3.27.2342. Только собственная новая файловая база
`/tmp/open-bsl-common-attribute-condition-order-1009-ib`.
CF и XML экспортированы read-only Designer после успешного контроля
`measure-common-attribute-metadata-condition-order.bsl` (4 строки).

Полный состав содержит три каталога и две константы. В двух профилях
меняется порядок явных записей Catalog.ЗамерВременныхТаблиц Use и
Constant.АКонстанта DontUse, включая ненулевое условие первого объекта.
Нативный порядок пяти элементов совпадает между профилями;
не совпадает с порядком явных XML Items или алфавитной сортировкой имён.
Сам по себе этот контроль не устанавливает порядок для всех классов
или другие режимы разделения. SHA256SUMS фиксирует десять артефактов.

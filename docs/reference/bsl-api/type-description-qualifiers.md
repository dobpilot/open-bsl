# Квалификаторы описания типов

`ОписаниеТипов` сохраняет квалификаторы приобретённых типов. Свойство
`Колонка.ТипЗначения` таблицы также сохраняет их.

Для строки доступны `КвалификаторыСтроки.Длина` и
`КвалификаторыСтроки.ДопустимаяДлина`; для числа —
`КвалификаторыЧисла.Разрядность`, `РазрядностьДробнойЧасти` и `ДопустимыйЗнак`.
Квалификаторы читаются, присваивание свойства описания запрещено.
Английские псевдонимы: `StringQualifiers.Length`,
`StringQualifiers.AllowedLength`, `NumberQualifiers.Digits`,
`NumberQualifiers.FractionDigits` и `NumberQualifiers.AllowedSign`.
Если соответствующего примитивного типа в описании нет, числовые параметры
его квалификаторов равны нулю.

```bsl
ОписаниеСтроки = Новый ОписаниеТипов("Строка", , Новый КвалификаторыСтроки(12));
ОписаниеЧисла = Новый ОписаниеТипов("Число", Новый КвалификаторыЧисла(38, 2));
```

Измерены переменная и фиксированная длина строки, числовая политика
`ДопустимыйЗнак.Любой`. Другие политики числа пока дают явную ошибку.
Фиксированная строка дополняется пробелами до заданной длины; длинная
строка обрезается. Эти правила используют общее приведение типов,
а не специальную обработку таблицы остатков.

Одиночные строковое и числовое описания форматируются как `Строка` и
`Число` в текущем русском представлении runtime. Текст перечислений
квалификаторов пока сохраняет прежние английские представления;
это известное расхождение с русским сеансом платформы.
Копирующие формы и представление составного описания этим изменением
не расширены.

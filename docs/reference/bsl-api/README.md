# BSL API

[`api.md`](api.md) — генерируемый каталог API стандартной сборки `open-bsl`:
глобальные функции, конструкторы, типы, методы и свойства. Источником имён и
псевдонимов служат те же runtime-дескрипторы, по которым компилятор и VM
разрешают вызовы. Описание строки — первое предложение doc-комментария
функции, которая её реализует (иначе — строки дескриптора), а «Реализация» —
файл этой функции. Генератор находит их в исходниках workspace и без них не
работает.

Обновление снимка:

```bash
cargo run -p bsl-cli -- --emit-api-reference docs/reference/bsl-api/api.md
```

Тест CLI сравнивает снимок с текущим выводом генератора. Если изменение API
преднамеренное, сначала меняется дескриптор и его тесты, затем этой командой
обновляется `api.md`. Снимок нужно обновить и после правки doc-комментария
реализации или переноса её в другой файл.

Отдельные Markdown-файлы в этом каталоге предназначены для пояснений,
примеров и совместимости с 1С. Они не должны вручную повторять списки имён из
`api.md`.

[Возможности по объектам](capabilities.md) — обзор по группам объектов: что
open-bsl исполняет, что только объявлено и чего нет; поимённые списки остаются
в `api.md`.

[Запуск приложения](application-launch.md) — выходной аргумент, возможности
CLI и host, ограничения Unix-запуска и отличия от серверной 1С.

[Очистка временных ресурсов](temporary-file-cleanup.md) — callback host,
завершение CLI/REPL и границы ещё не завершённой системной реализации.

[Ссылка на модуль](module-reference.md) — тождество `ЭтотОбъект`, экспортные
получатели описаний оповещения, доставка Begin и оставшиеся границы совместимости.

[Квалификаторы описания типов](type-description-qualifiers.md) — сохранение
квалификации колонок, приведение фиксированной строки и измеренные ограничения.

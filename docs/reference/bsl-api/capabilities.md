# Возможности open-bsl по объектам

Обзор того, что стандартная сборка `open-bsl` умеет исполнять, а что нет,
по группам объектов встроенного языка. Состояние на 23.10.2026.

Страница описывает объекты и их назначение. Поимённых списков функций,
конструкторов и методов здесь нет: они генерируются из runtime-дескрипторов
в [`api.md`](api.md) вместе с описаниями и файлами реализаций, и правдой считается именно этот
файл. Если обзор и `api.md` расходятся, верен `api.md`, а обзор надо
поправить.

## Как читать состояние

| Пометка | Что значит |
|---|---|
| есть | Объект создаётся и работает. Поведение сверено с платформой 8.3.27 замерами или задано документацией 1С там, где замер показал ошибку платформы. |
| частично | Основная часть работает, отдельные возможности отсутствуют или ограничены; они перечислены в последней колонке. |
| объявлено | Имя известно компилятору: код компилируется, но вызов или `Новый` поднимает исключение «объявлено без реализации в open-bsl». Такое исключение ловится `Попытка`. |
| нет | Имени нет совсем: модуль, который его использует, не компилируется. |

Проверить конкретное имя проще всего поиском по [`api.md`](api.md): имя без
пометки реализовано, с пометкой *объявлено без реализации* — только объявлено.
Исключение — типы, которые VM создаёт сама (`Массив`, `Структура`,
`Соответствие`, `ТаблицаЗначений` и их члены): их нет в `api.md`, но они
реализованы. Для остальных имён отсутствие в `api.md` означает «нет».

## Язык и исполнение

| Возможность | Состояние | Что умеет | Ограничения |
|---|---|---|---|
| Синтаксис модуля, процедуры и функции, `Знач`, умолчания параметров | есть | Полный конвейер: разбор, семантика, байт-код, VM; русские и английские ключевые слова. | — |
| `Попытка`/`Исключение`, `ВызватьИсключение`, `ИнформацияОбОшибке` | есть | Ошибки времени исполнения ловятся как в 1С, с описанием и контекстом модуля. | — |
| `Перейти`/`Goto` и метки | есть | Числовые и именованные метки, переходы вперёд и назад ([goto.md](../language/goto.md)). | — |
| Препроцессор `#Если`, `#Область` | есть | Условная компиляция по символам контекста ([preprocessor.md](../language/preprocessor.md)). | Символы задаёт контекст исполнения: интерпретатор работает как сервер, клиента с интерфейсом нет. |
| `Выполнить`, `Вычислить` | есть | Динамические фрагменты компилируются тем же компилятором; есть кэш. | — |
| `Асинх`/`Ждать`, `Обещание`, `ОписаниеОповещения` | есть | Асинхронные функции и `Начать…`-методы файлов доставляют результат по тикам VM. | Есть только тот цикл событий, что ведёт сама VM; интерактивных диалогов, которых можно ждать, нет. |
| Общие модули из файлов `//@используй` | есть | Расширение open-bsl: несколько файлов собираются в граф модулей ([module-inclusion.md](../language/module-inclusion.md)). | На платформе такой директивы нет. |
| Фоновые задания | есть | `ФоновыеЗадания.Выполнить` выполняет экспортные методы общих модулей в пуле потоков. | — |
| Внешние компоненты (`ПодключитьВнешнююКомпоненту`) | частично | Вызов существует в сеансе конфигурации. | Загрузчик компонент штатный хост не передаёт, поэтому вызов завершается ошибкой. |
| COM (`COMОбъект`, `COMSafeArray`) | объявлено | — | COM не поддерживается. |

## Примитивы и универсальные коллекции

| Объекты | Состояние | Что умеет | Ограничения |
|---|---|---|---|
| `Число`, `Строка`, `Дата`, `Булево`, `Неопределено`, `Null`, `Тип` | есть | Десятичная арифметика без потери точности (`bsl-number`); `Формат` и `Строка` по правилам 1С (`bsl-format`); строковые и математические функции. | `ЧислоПрописью`, `СтрокаСЧислом`, склонения и `ПредставлениеПериода` объявлены без реализации. `Тип("…")` принимает несколько имён, которые платформа отвергает. |
| `Массив`, `Структура`, `Соответствие`, фиксированные варианты | есть | Создание, обход, все основные методы. | — |
| `СписокЗначений` | есть | Элементы, пометки, сортировка, выгрузка. | Интерактивные методы выбора из списка не имеют смысла без интерфейса. |
| `ТаблицаЗначений`, индексы, колонки | есть | Поиск, отборы, `Свернуть`, `Итог`, сортировка, копирование, индексы. | — |
| `ДеревоЗначений` | объявлено | — | Конструктор объявлен без реализации. |
| `ОписаниеТипов`, квалификаторы | есть | Приведение значений, квалификаторы строки, числа и даты ([type-description-qualifiers.md](type-description-qualifiers.md)). | — |
| `УникальныйИдентификатор`, `МоментВремени`, `Граница` | есть | — | — |
| `ДвоичныеДанные`, `БуферДвоичныхДанных` | есть | Base64, Hex, побитовые операции, срезы и разделение (`bsl-binbuf`). | — |
| `ГенераторСлучайныхЧисел`, `Диапазон` | объявлено | — | Конструкторы объявлены без реализации. |

| `МенеджерКриптографии`, `СертификатКриптографии` | объявлено | — | Электронной подписи и шифрования нет. |

## Конфигурация и данные

Эти объекты работают в сеансе конфигурации (`bsl-session`, `bsl-orm`). Код и
описания объектов берутся из информационной базы или из выгрузки XML/EDT, а
данные, пользователи и права — из базы PostgreSQL или MS SQL через
`--config-db` ([configuration-session-cli.md](../configuration-session-cli.md),
[configuration-file-sources.md](../configuration-file-sources.md)). Без сеанса
конфигурации в простом запуске скрипта они недоступны.

| Объекты | Состояние | Что умеет | Ограничения |
|---|---|---|---|
| `Метаданные`, объекты и коллекции метаданных, перечислимые свойства | есть | Состав конфигурации, реквизиты, свойства, синонимы. | — |
| Справочники, документы, планы видов характеристик, бизнес-процессы, обработки, отчёты: менеджеры, ссылки, объекты, табличные части | есть | Создание, заполнение, запись, проверка заполнения, обработчики событий модулей объекта и менеджера. | — |
| Регистры сведений, движения документов | есть | Наборы записей, `КоллекцияДвижений`. | — |
| `Запрос`, `РезультатЗапроса`, выборки, `МенеджерВременныхТаблиц`, `СхемаЗапроса` | есть | Исполнение запросов через `open-sdbl` с правами и RLS пользователя. | — |
| Компоновка данных: компоновщики, процессоры, вывод в коллекцию значений | частично | Настройки и вывод результата в коллекцию значений. | Макеты компоновки, `ОтборКомпоновкиДанных`, данные расшифровки объявлены без реализации. |
| Транзакции, привилегированный режим, `БлокировкаДанных` | есть | `НачатьТранзакцию`, вложенность и откат, `УстановитьПривилегированныйРежим`. | — |
| Пользователи ИБ, роли, политики паролей, `ГенераторСлучайныхПаролей` | есть | Чтение пользователей и прав, проверка ролей. | — |
| Параметры сеанса, хранилища настроек, функциональные опции | есть | Модуль сеанса, `ХранилищеОбщихНастроек`, функциональные опции с правами. | `БлокировкаСеансов` объявлена без реализации. |
| Расширения конфигурации | есть | Описания расширений базы и их назначение. | — |
| Защищённые модули поставщика | частично | По умолчанию — экспортные заглушки. | Восстановление тел — только по явному `--decompile-protected-modules`; права на декомпиляцию подтверждает пользователь. |

## Интерфейс клиента

Пользовательского интерфейса в open-bsl нет: интерпретатор исполняет код как
сервер, без окна приложения.

| Объекты | Состояние | Ограничения |
|---|---|---|
| Управляемые формы, `РеквизитФормы`, `ДанныеФормыВЗначение`, `ЗначениеВДанныеФормы`, `КопироватьДанныеФормы` | объявлено | Форм нет. |
| `ОткрытьФорму`, `Вопрос`, `Предупреждение`, `ПоказатьВопрос` и прочие диалоги | нет | Модуль с такими вызовами не компилируется. |
| `Сообщить`, `СообщениеПользователю` | есть | Сообщения выводятся в поток вывода хоста. |
| `ЦветаСтиля`, `ШрифтыСтиля`, `WebЦвета`, `СочетаниеКлавиш`, избранное, `ДоставляемоеУведомление` | объявлено | Оформления и уведомлений клиента нет. |
| `ЗапуститьПриложение` | есть | Запуск процесса операционной системы ([application-launch.md](application-launch.md)). |

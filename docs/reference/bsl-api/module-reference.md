# Ссылка на исполняемый модуль

`ЭтотОбъект` возвращает тождественную ссылку на текущий экземпляр BSL-модуля
open-bsl. Это не объект управляемой формы 1С. Ссылка одинакова в теле модуля,
его функциях, асинхронных процедурах и принадлежащих ему динамических
фрагментах. Повторный запуск создаёт новый экземпляр. Общие модули каталога
имеют отдельные ссылки, не совпадающие со ссылкой entry-модуля.

```bsl
Процедура Обработать(Результат, Данные) Экспорт
КонецПроцедуры

Ссылка = ЭтотОбъект;
Сообщить(Ссылка = Вычислить("ThisObject")); // Да
Описание = Новый ОписаниеОповещения("Обработать", Ссылка);
```

Конструктор описания проверяет наличие экспортного метода, но не исполняет
его. Неэкспортный метод отвергается. Ссылку можно хранить в коллекции и
использовать как ключ соответствия; это не копия модульных переменных.
Тип ссылки — собственный тип open-bsl, не платформенный тип 1С.

Прямой вызов `Ссылка.Обработать(Результат, Данные)` исполняет экспортный
метод в VM. Поддержаны процедуры/функции, Знач, ссылочные параметры,
умолчания и явное Неопределено; арность и контекст результата проверяются
до входа в метод. Async-методы используют общий планировщик. Работают
взаимные вызовы entry и общих модулей каталога.

Вычислить возвращает BSL-обещание текущего запуска без ожидания дочерней
задачи. Прямые модульные вызовы и динамические фрагменты разделяют живую
ячейку параметра с модульной переменной, включая переключения задач и
исключения. Вызванные из фрагмента статические функции сохраняют каталог
и импортные инструкции; callback через ссылку на другой модуль использует
его исходный экземпляр. Статический вызов
локальной функции также сохраняет ссылочную цель аргумента вида
Импорт.Переменная и подготавливает её ленивого владельца
до входа в функцию.

Динамическая строка видит объявленные импорты исходного модуля под его
псевдонимами, включая импорты без статических обращений. Вложенная строка
сохраняет это окружение; функция другого модуля использует своё.
Неимпортированный модуль и неэкспортный символ недоступны. Локальная или
модульная переменная затеняет одноимённый псевдоним. Эти правила сохраняются
после загрузки байткода; формат 32 содержит отдельную таблицу импортов,
поэтому образы прежних версий нужно пересобрать.

Прямые квалифицированные async-вызовы через импорт по-прежнему отклоняются
согласно прежнему ограничению `JOB.ASYNC.TARGET`. Это отличается от вызова
через ссылку на модуль; синхронная экспортная функция может вернуть обещание
такого вызова для ожидания снаружи.

Ждать внутри строки
отвергается при компиляции фрагмента, в том числе из async-метода, как
в измеренной 1С. Возвращённое из Вычислить обещание ожидают снаружи.
Отладочное evaluate пока остаётся отдельным блокирующим
исполнителем с ограничениями каталога и владельца BSL-обещания.

Измеренные Begin-методы Файл доставляют оповещения через планировщик VM.
Само создание описания ничего не запускает. Чтение и инициализация передают
обработчику результат и дополнительные данные; setter — только данные.
Доставка отложена относительно вызова метода и сохраняется после возврата
основного тела скрипта. Ошибка операции передаёт ИнформациюОбОшибке,
изменяемый флаг стандартной обработки и дополнительные данные; присваивание
флагу Ложь, 0 или строки "False" отключает стандартную обработку. Неприводимый
флаг сохраняет исходную ошибку операции. В CLI неотключённая ошибка
возвращается как обычная ошибка исполнения, без модального окна 1С.
Отмена исполнения прекращает оставшиеся доставки, но не откатывает I/O.
Измерены также функции и async-обработчики успеха; исключение async-функции
остаётся в её неиспользуемом обещании, исключение процедуры передаётся host.
Ошибка обработчика успеха не перенаправляется обработчику ошибки операции.
Async-обработчик ошибки, его исключения и прочие значения флага ещё не измерены:
[состояние проверки](../../research/compatibility/file-begin-handler-kinds-2026-09-17.md).

Как у других глобальных свойств open-bsl, допустима функциональная запись
`ЭтотОбъект()`. Локальная или модульная переменная одноимённого написания
перекрывает чтение глобального свойства; второй языковой псевдоним остаётся
отдельным именем. Публичного конструктора ссылки нет. Сохранённая ссылка
не удерживает завершённый экземпляр модуля и его переменные.

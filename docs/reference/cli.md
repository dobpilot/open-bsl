# Командная строка

Актуальная краткая справка строится таблицей `COMMANDS`:

```bash
cargo run -p bsl-cli -- --help
```

Основные формы запуска и команды также перечислены в корневом `README.md`.
Новая команда добавляется одной строкой в `COMMANDS` и отдельной веткой
исчерпывающего `match` по `Kind`; ручная вторая таблица команд недопустима.

`--emit-api-reference [выход.md]` печатает Markdown-справочник публичного BSL
API в stdout либо записывает его в указанный файл.

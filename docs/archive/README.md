# Архив

Архив объясняет происхождение текущего устройства, но не является
нормативным описанием. Актуальный контракт следует искать в
[`../architecture/`](../architecture/), [`../reference/`](../reference/) и
[`../../openspec/specs/`](../../openspec/specs/).

- [`refactors/component-abi-f.md`](refactors/component-abi-f.md) — история
  принятия компонентного ABI и публичной границы встраивания. Остальные
  исторические планы доступны в истории Git; их действующие выводы перенесены
  в архитектуру, этот документ и активные планы.
- [`plans/`](plans/) — реализованные планы функций.

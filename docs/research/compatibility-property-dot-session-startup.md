# Доступ через точку к режиму совместимости

После подключения начального динамического состояния исходный demo
завершился `UnknownProperty("НеИспользовать")`. Чтение исходников только
для чтения обнаружило обращение
`Метаданные.СвойстваОбъектов.РежимСовместимости.НеИспользовать` в
`ОбщегоНазначения.ВерсияРежимаСовместимости`.
Журнал поиска —
`target/diagnostics/readonly-startup/demo-dont-use-source-1013-startup.log`.

В runtime `MetadataPropertyEnumeration::get_property` отдельно отвергал
именно `CompatibilityMode`, сохраняя ранее реализованный индексный путь.
Прямой нативный контроль на собственной базе 8.3.27.2342 дал восемь полных
строк: `DontUse`, тип `Compatibility mode`, равенство точки и индекса,
русского и английского имён, значение `Version8_3_24` и его псевдоним.
Скрипт, oracle и хеши — `fixtures/compatibility-property-dot/`.

OpenSpec `support-reached-compatibility-property-dot` строго провалидирован
до удаления специальной ветки отказа. Остался существующий единый поиск
члена; неизвестные свойства по-прежнему отвергаются. Голое имя и регистрация
имени типа не расширены. Новый внешний интеграционный тест исполняет весь
native control, проверяет регистр и неизвестный член. Он прошёл, как и
существующий `configuration_metadata_exposes_the_measured_compatibility_mode`,
без изменения его ожиданий. Clippy для всех целей `bsl-orm` прошёл.

Повторный исходный demo запущен неизменяемым бинарным файлом
`session-cdot-startup-probe-1013` в прежнем изолированном read-only контуре.
Итог следует брать после завершения из
`target/diagnostics/readonly-startup/demo-compatibility-dot-1013-startup.log`.
Этот документ пока не подтверждает прохождение данного места оригинальным
сеансом или успешную инициализацию.

Повтор завершился с кодом 1 за 143,52 с. Прежний отказ пройден;
следующий — `СписокЗначений.НайтиПоЗначению` не найден.
Наблюдаемый пик RSS 7 167 748 КиБ. Полная инициализация не достигнута.

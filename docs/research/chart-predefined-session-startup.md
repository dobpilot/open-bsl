# Предопределённые счета при инициализации buh

Нативный контроль 1С 8.3.27.2342 сохранён в `fixtures/chart-predefined-manager`. Bare имя собственного менеджера, квалифицированное свойство и результат VALUE совпадают; метаданный GUID не является UUID записи.

Реализация расширяет существующие фильтры владельцев, типы ссылок и декларации свойств менеджера. Два теста `chart_predefined_references` проверяют владельца и запись, текущего principal адаптера, точный запрос, aliases, отказ записи, bare имя, локальную и модульную переменные, отсутствие контекста в постороннем модуле. Целевой Clippy и форматирование прошли.

Повторный read-only запуск оригинального buh занял 190.34 с, получил 9976 модулей и прошёл прежнюю ошибку UndefinedVariable(ОбщехозяйственныеРасходы). Следующая ошибка: `ПланСчетов.Хозрасчетный.МодульМенеджера`: `UndefinedFunction(ПустаяСсылка)`. Полный запуск не завершён успешно. Квитанция: `target/diagnostics/readonly-startup/buh-chart-1013-startup.log`.

Изолированный бинарник использует подготовленный SDK 3ff9202 и частные диагностические копии адаптера; результат не доказывает зелёный прогон основного workspace или готовность SDK main.

Дополнительный завершённый нативный контроль `fixtures/chart-predefined-manager/empty-ref` подтверждает qualified/bare ПустаяСсылка и EmptyRef, nil UUID, IsEmpty, тот же тип ссылки. Добавлена только эта достигнутая операция через существующий конструктор ссылок. Два целевых теста проходят после дополнения; целевой Clippy, русская rustdoc с `-D warnings` и генерация справочника проходят. Повторный оригинальный запуск с методом ещё выполняется; успешный итог не заявлен.

Повторный запуск с EmptyRef завершился отказом за 189.03 с: прежняя ошибка метода пройдена, следующая `UndefinedFunction(ПолучитьМакет)` в том же модуле менеджера. Квитанция `target/diagnostics/readonly-startup/buh-chart-empty-1013-startup.log`. Этот прогон не передавал строку соединения; компиляционная ошибка возникла до её чтения, но результат нельзя считать полным повторением host-контекста предыдущих запусков.

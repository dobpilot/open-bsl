# Flamegraph: current против `main`

Замер снят 18 сентября 2026 года на одной машине. База — `main`
`22fa7c07a48b018e030252fac22bc374d22a8618`, текущая сторона — рабочее
дерево над `1335406cba2d957999fd4a254b819da976ce66f4`, включая
его незакоммиченные изменения.

Обе стороны собраны профилем `profiling` с
`RUSTFLAGS='-C force-frame-pointers=yes'`. Benchmark-сценарии между
ветками не различаются. Flamegraph сняты через
`perf record -F 997 -e cycles:u --call-graph fp`.

## A/B-счётчики

Пять чередующихся пар на profiling-бинарниках. Дельта —
`current / main - 1`; в скобках указан полный диапазон пар.

| Сценарий | Такты | Инструкции |
|---|---:|---:|
| `json_write` | −4,79% (−5,87…−3,20%) | +2,58% (+2,58…+2,59%) |
| `xml_parse` | +2,91% (+0,98…+5,20%) | +1,62% (+1,61…+1,64%) |
| `xml_write` | −0,31% (−1,70…+0,66%) | +0,44% (+0,37…+0,51%) |

Число инструкций даёт устойчивый вердикт во всех пяти парах.
Такты шумят сильнее: `xml_write` пересекает ноль, а `json_write`
на этом прогоне быстрее `main`. Стабильный вердикт даёт число инструкций.
Сырые пары находятся в [`ab.csv`](ab.csv).

## Профиль VM

Инклюзивная доля `step_cold`:

| Сценарий | `main` | `current` |
|---|---:|---:|
| `json_write` | 57,09% | 55,27% |
| `xml_parse` | 42,78% | 43,07% |
| `xml_write` | 66,83% | 69,27% |

В `json_write` связанный вызов компонентного метода снизил долю
`step_cold` относительно `main`. В XML-сценариях общий горячий
путь текущей ветки всё ещё тяжелее `main`; дифференциальные
графики показывают распределение разницы по стекам. Они
нормализованы к одному миллиону сэмплов: красный означает рост
доли в current, синий — снижение.

## Артефакты

- `main-*.svg` и `current-*.svg` — обычные flamegraph.
- `diff-*.svg` — нормализованные дифференциальные flamegraph.
- `*.folded` — свёрнутые стеки; `*.report.txt` — текстовые `perf report`.

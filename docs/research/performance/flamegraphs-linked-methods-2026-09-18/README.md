# Связанные вызовы методов компонентов

Замер снят 18 сентября 2026 года на одной машине. Обе стороны содержат
одинаковый код; сторона `open` отключает только объявления типов результатов
конструкторов JSON и XML и тем самым сохраняет прежние
`CallObjectMethod`/`CallObjectProcedure`. Сторона `linked` выпускает
`CallLinkedObjectMethod`/`CallLinkedObjectProcedure` и разрешает
`MethodDescriptor` до первой инструкции.

## Чередующийся A/B

Пять пар, порядок сторон менялся в каждой паре. Счётчики сняты с release-сборок
через `perf stat -e instructions:u,cycles:u`. Дельта — `linked / open - 1`, в
скобках полный диапазон пар.

| Сценарий | Такты | Инструкции |
|---|---:|---:|
| `json_write` | −4,96% (−5,44…−4,36%) | −3,29% (−3,29…−3,28%) |
| `xml_parse` | +0,68% (−0,55…+3,84%) | −1,33% (−1,35…−1,31%) |
| `xml_write` | −3,88% (−4,73…−3,25%) | −2,36% (−2,38…−2,34%) |

Сырые пары находятся в [`ab.csv`](ab.csv).

## Flamegraph

Обе стороны собраны профилем `profiling` с
`RUSTFLAGS='-C force-frame-pointers=yes'`. Профили сняты через
`perf record -F 997 -e cycles:u --call-graph fp`.

В прежнем открытом пути видны расходы `open_call_site` и
`cached_object_method_plan`: в `json_write` последний занимает около 2,46%
профиля, в `xml_write` один `open_call_site` — около 2,06%. В связанных
профилях эти ветви отсутствуют. Инклюзивная доля `step_cold` снизилась:

| Сценарий | `open` | `linked` |
|---|---:|---:|
| `json_write` | 69,83% | 61,66% |
| `xml_parse` | 44,92% | 43,46% |
| `xml_write` | 71,78% | 64,33% |

Для каждой стороны сохранены `.svg`, свёрнутые стеки `.folded` и текстовые
отчёты `perf report`.

## Предварительная проверка call-site

После исходного замера в связанную запись вынесены число аргументов
и результат успешных проверок арности/использования результата. Ошибочные
вызовы по-прежнему проверяются в точке исполнения и остаются ловимыми.

Пять чередующихся пар против бинарника до этой правки:

| Сценарий | Такты | Инструкции |
|---|---:|---:|
| `json_write` | −0,89% (−2,07…+0,16%) | −1,80% (−1,80…−1,80%) |
| `xml_parse` | −1,06% (−2,26…+1,70%) | −0,81% (−0,84…−0,79%) |
| `xml_write` | −0,88% (−2,59…+0,99%) | −1,26% (−1,32…−1,18%) |

Сырые пары сохранены в
[`callsite-prevalidation-ab.csv`](callsite-prevalidation-ab.csv).

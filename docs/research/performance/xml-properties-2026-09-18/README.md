# XML: свойства имени без промежуточных строк

Продолжение [устранения строки закрывающего тега](../xml-end-name-2026-09-18/README.md).
База — рабочее дерево после той правки, не `main`. Сохранённые release-
бинарники: `/tmp/open-bsl-xml-properties-before` и
`/tmp/open-bsl-xml-properties-after`. Эти файлы временные; результаты
измерений сохранены рядом с отчётом.

## Изменение

`ЛокальноеИмя` и `Префикс` раньше сначала получали `Имя` как BSL-строку,
преобразовывали её обратно в UTF-8, выделяли часть имени и создавали
ещё одну BSL-строку. Теперь общий закрытый метод `current_name` отдаёт
заимствованное имя текущего узла или атрибута. Каждое свойство создаёт
только итоговую BSL-строку. `URIПространстваИмен` также использует
заимствованный URI вместо клонирования String.

API, выбор текущего имени, семантика курсора атрибутов и URI не меняются.
Внутренний рефакторинг не требует нового OpenSpec change. Arena и CoW
не вводятся. Новый тест прошёл до и после правки: отсутствие узла,
текст, комментарий, сущность, инструкция обработки, начало и конец
элемента, курсор атрибута, префиксы и Unicode. Все 180 тестов bsl-xml прошли.

## Измерительный вариант

Штатный xml_parse читает `Имя`, но не `ЛокальноеИмя` и `Префикс`.
Поэтому основной эффект измеряется отдельно на `xml_local_name`:
копии xml_parse с единственной заменой `Чтение.Имя =` на
`Чтение.ЛокальноеИмя =`. Документ не использует префиксы, контрольный
результат остаётся прежним. Исходный benchmark не изменён.

Воспроизведение варианта:

```sh
sed 's/Чтение\.Имя =/Чтение.ЛокальноеИмя =/' benchmarks/xml_parse.bsl > /tmp/open-bsl-xml-local-name.bsl
```

Счётчики получены примером alloc-profile, отдельно от замеров скорости.

| Суммарно запрошено байт | 632 406 988 | 535 326 334 |
| Пик живых запрошенных байт | 77 074 926 | 77 074 926 |

Убрано 2 940 018 запросов, включая 540 006 realloc, и 97 080 654
суммарно запрошенных байт. Подготовка не изменилась. У штатного xml_parse
все счётчики до/после одинаковы. Контрольный вывод обоих сценариев совпал.
Выигрыш свойств `Префикс` и URI отдельно не измерялся.

## Чередующийся A/B

Пять пар на сценарий, порядок сторон чередуется. Обычная release-сборка
без переопределения RUSTFLAGS, без `--optimize` и без измерительного
аллокатора. Запуск: `perf stat -x ';' -e instructions:u,cycles:u --
<binary> <script>`. Инструкции и такты — весь процесс, время — штатный
таймер основного цикла. Вывод без строки времени сверялся на всех запусках.
Все 40 результатов — в ab.csv. Изменение вычислено для каждой пары как
`(after / before - 1) * 100`, затем усреднено.

| Сценарий | Инструкции, среднее (диапазон), % | Такты, среднее (диапазон), % | Внутреннее время, среднее (диапазон), % |
|---|---:|---:|---:|
| json_write | −0,001 (−0,003…−0,000) | −0,04 (−2,70…+3,59) | −0,36 (−3,33…+4,22) |
| xml_parse | −0,06 (−0,06…−0,06) | +0,98 (−1,86…+3,28) | +1,31 (−1,82…+3,80) |
| xml_local_name | −7,00 (−7,04…−6,97) | −9,37 (−11,86…−8,17) | −9,76 (−12,91…−8,28) |
| xml_write | −0,007 (−0,018…+0,016) | +2,92 (−1,21…+15,60) | +2,22 (−2,34…+14,09) |

Ускорение подтверждено для варианта с ЛокальноеИмя, не для штатного
xml_parse. Диапазоны времени штатных сценариев пересекают ноль; на рабочей
машине шум и влияние размещения кода не исключены. Пик памяти не уменьшился.

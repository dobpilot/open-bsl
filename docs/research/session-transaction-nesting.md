# Вложенные транзакции для адаптера сеанса

2026-10-12, настоящая 1С 8.3.27.2342, собственные временные файловые базы.
Оригинальные demo/buh/unf не использовались. Замеры нужны для подключения
приобретённого SDK API к достигнутым транзакционным вызовам demo.

`measure-session-transaction-nesting.bsl` дал 19 строк в собственной
`/tmp/open-bsl-session-transaction-nesting-1012-ib`. Вложенный begin допустим;
внутренний commit и rollback оставляют транзакцию активной. Внешний commit
завершает её. Commit и rollback без begin отказывают. Пустой контроль не
доказывает результат сохранения данных.

Поэтому `measure-session-transaction-rollback-data.bsl` дополнительно выполнен
в собственной `/tmp/open-bsl-functional-option-content-1012-ib` с булевой
константой `ЗначениеОпцииПробы`. Перед началом установлена Ложь, внутри внешней
транзакции — Истина, затем выполнены вложенный begin и rollback. Получены
все восемь строк первоначального контроля:

- После внутреннего rollback `ТранзакцияАктивна()` возвращает Истину.
- Чтение константы до внешнего завершения отказывает.
- Внешний commit завершается успешно, активность становится Ложью.
- Последующее чтение возвращает Ложь: запись не сохранилась.
- Исходное значение константы восстановлено и проверено.

Первый вариант пробы остановился на отказавшем чтении и дал только пять строк;
он не считается подтверждением внешнего commit. Второй ловит этот отказ
отдельно и сохраняет полный результат. Эталоны находятся рядом с обоими BSL
скриптами в `tests/conformance/measure/1c/`; ingest не выполнялся.

SDK предоставляет невложенную реальную read-only-транзакцию соединения.
При адаптации нельзя трактовать внутренний rollback как обычное уменьшение
счётчика с последующей реальной фиксацией. Нужны измеренная вложенность,
отказ чтений после отмены и реальный откат на внешней границе. Дополнительный контроль повторного begin после внутренней отмены дал Истину;
финальный эталон содержит 10 строк и подтверждает очистку до неактивного
состояния. Поведение при потере соединения этими платформенными пробами
не измерено.

# Создание группы справочника: нативные результаты

На 1С 8.3.27.2342 выполнены четыре независимые пробы в изолированных
файловых базах. Рабочие базы и исходники не изменялись.

- Иерархия групп и элементов: тело модуля читает `ЭтоГруппа=false`,
  присваивание запрещено. После `СоздатьГруппу` признак равен true;
  английское имя свойства совпадает, тип Boolean, запись запрещена.
- Неиерархический справочник: вызов успешен, но тело и возвращённый
  объект имеют `ЭтоГруппа=false`.
- Иерархия элементов: `СоздатьГруппу` отклоняется с сообщением
  `This catalog cannot contain groups!`.
- Выключенная иерархия при сохранённом виде `HierarchyOfItems`: метод тоже
  отклоняется с тем же сообщением. Приоритет вида нельзя выводить из флага
  `Hierarchical=false`; четвёртая проба проверила этот случай отдельно.

Артефакты: `measure-catalog-create-folder-{hierarchical,flat,items,flat-items}.bsl`
и соответствующие `.platform.txt` в `tests/conformance/measure/1c`.
Первый запуск items не дошёл до исполнения из-за ошибочного XML
`HierarchyItems`; исправленный `HierarchyOfItems` принят платформой.
Неудачная подготовка не включена в результаты семантики.

Существующее создание элемента следует переиспользовать: собственная
память, стандартные реквизиты и запуск тела уже находятся в одном месте.
Признак группы устанавливается после тела, перед возвращением объекта.
Для корректного выбора пути нужен приобретённый вид иерархии, а не
предположение по одному флагу `catalog_hierarchical`.

Проверки реализации: fmt, Clippy, полный набор workspace, rustdoc с запретом
предупреждений, сборка open-bsl-consumer, деревья зависимостей ядра и VM
и strict OpenSpec прошли. Существующие ожидания тестов не изменялись.

Повтор исходных конфигураций продвинулся до следующих барьеров:
demo — СоздатьЭлемент в модуле менеджера плана видов характеристик
ДополнительныеРеквизитыИСведения; unf — ПолучитьМакет в модуле менеджера
регистра сведений СеансовыеДанныеGoogle. Маркер пользовательского скрипта
не достигнут: успешная инициализация сеансов пока не подтверждена.

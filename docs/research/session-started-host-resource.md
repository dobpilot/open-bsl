# Начало текущего сеанса

Исходный demo после исправления бинарного хеша расширения достигает
`ПолучитьТекущийСеансИнформационнойБазы().НачалоСеанса`.
Нативный контроль 1С 8.3.27.2342 в
`docs/research/fixtures/session-started` содержит семь завершённых строк:
тип `Дата`, непустое значение, alias `SessionStarted`, равенство повторных
чтений и отказ присваивания. Полная страница справки:
`platform-syntax-help:syntax-context:objects/catalog63/catalog732/InfoBaseSession/properties/SessionStarted7561.html`.

`SessionResources::with_session_started` принимает неизменное значение
конкретного сеанса до вызова обработчика инициализации. Getter возвращает
именно его; текущие часы на каждом чтении не вызываются. Если хост не
передал значение, чтение явно завершается ошибкой. Фоновый сеанс использует
свои ресурсы; дата родителя не наследуется.

CLI захватывает дату непосредственно перед `SessionFactory::open`,
используя стандартные часы, стандартный часовой пояс и существующий
`local_date_from_utc_seconds`, реэкспортированный через фасад. Это время
начала сеанса нашего хоста, а не приобретённая телеметрия сеанса сервера 1С.

Три новых публичных интеграционных теста прошли: весь нативный контроль,
доступность до завершения инициализации, отсутствие ресурса и изоляция
отдельных/фонового сеансов. Facade consumer и production-цели Clippy
прошли; rustdoc без предупреждений. Справочник API перегенерирован.

Существующий unit-test helper напрямую создаёт `SessionRuntime`. Для
его компиляции требуется ровно одна механическая строка
`session_started: None`, без изменения ожиданий. Патч
`target/diagnostics/session-started-existing-test-fixture.patch` пока
не применён. Вместе с коррекцией старого HashSum-ожидания он включён
в `target/diagnostics/host-session-existing-tests.patch`; для полного
прогона требуется согласование по действующему правилу пользователя.

Повторный read-only demo прошёл свойство и остановился на непереданном
признаке динамического изменения конфигурации, который уже блокировал UNF.
Лог: `target/diagnostics/readonly-startup/demo-session-started-1013-startup.log`.
Терминальный код — 1, наблюдавшийся пик RSS — 2 633 836 КиБ.
Это не подтверждает завершение исходной инициализации. `Ложь` для нового
отказа не подставлялась; сначала нужен доказательный нативный контроль.

# Исправление измерительного ControlNative

Ошибка `СтрРазделить` на строках 5 и 19 относится к первоначальному
контролю прав, который не скомпилировался при режиме совместимости
`Version8_2_16`. Исправленный измерительный модуль использует явные массивы
для имён пользователей и проверяемых прав. Режим совместимости исходной
конфигурации не менялся; ошибка не требует расширять open-bsl.

Агент выполнил нативный `ibcmd config export objects` для реально загруженного
`CommonModule.ControlNative` из обеих собственных успешных контрольных баз
`missing-users4-ib` и `empty-users5-ib`. Оба экспорта завершились с кодом 0.
Их модули имеют одинаковый SHA-256:
`726d4b27e2a5f17b44fa562c5216379d4d933bc697c853dbfd12be4ad00dfda3`.
Root независимо проверил хеши файлов и наличие явных массивов при отсутствии
`СтрРазделить`. Квитанции сохранены в
`fixtures/role-control-compiled/loaded-role-controls.json`.

Это проверка фактически загруженных исправленных модулей, а не вывод
из состояния генератора. В исходные demo/buh/unf исправления не вносились.

# Пустая коллекция точек маршрута

Замер выполнен 2026-10-06 на платформе 1С 8.3.27.2342 в собственной
тестовой базе `/tmp/open-bsl-business-task-reference-097-ib`.
Исходные базы demo, buh и unf не изменялись.

`empty.bsl` — исполняемый зонд; `empty.platform.txt` — результат платформы.
У собственного бизнес-процесса `ЗамерБизнесПроцесса` без точек свойство
`ТочкиМаршрута` доступно: количество равно нулю, обход не выполняет
ни одной итерации. Представление типа снято в английской локали.
Этот замер не устанавливает состав, порядок или свойства непустой коллекции.

Справка установленной платформы подтверждает доступное только для чтения
свойство менеджера `ТочкиМаршрута` / `RoutePoints` с типом `ТочкиМаршрута`.
Идентификатор страницы:
`platform-syntax-help:syntax-context:objects/catalog125/catalog702/object705/properties/RoutePoints3055.html`.

При отдельном чтении исходника менеджера `БизнесПроцесс.Исполнение`
из demo обнаружены обращения к четырём именам: `Исполнить`,
`ОтветственноеИсполнение`, `Контролировать`, `Проверить`.
Они используются для сравнения с точкой маршрута задачи. Исходник
прочитан без исполнения; перечень этих обращений не заменяет полный
состав точек из метаданных конфигурации.

В open-sdbl 0.9.8 состав предоставлен вложенными значениями
`BusinessProcessRoutePoint`; тип ссылки предоставлен отдельно.
Идентичность члена — владелец и GUID точки: нативные процессы demo
могут содержать одинаковые GUID точек. Проверенная пустая коллекция
отличается от неизвестной или неполной формы. Подставлять пустую
коллекцию при отсутствии сведений нельзя.

После замера пустой карты агент SDK создал в этой же собственной базе
непустую карту штатным Designer. Артефакты нативной XML/Config находятся
в `open-sdbl/tests/fixtures/native-098/`; карта имеет 10 точек всех девяти
доступных видов, а также линии и декорацию. Незавершённые связи и
обработчики не позволяют считать её исполнение проверенным.

`nonempty.bsl` и `nonempty.platform.txt` снимают чтение коллекции без
запуска бизнес-процесса. Количество и число итераций — 10; порядок обхода
совпадает с порядком этой нативной карты. Доступ `действие1` совпадает
с `Действие1`, другая точка не равна первой. Точка заполнена;
представление `ВыборВарианта1` — `Выбор варианта1`, поэтому одного имени
без приобретённых синонимов для представления недостаточно.

`assignment.bsl` и его нативная квитанция уточняют присваивание:
запись другой точки и числа 42 в известный член коллекции принимается,
но ссылка остаётся прежней. Присваивание самому свойству менеджера
отвергается. Неизвестный член при чтении даёт ошибку. Эти замеры не
устанавливают все варианты индексов и присваивания неизвестным именам.

Дополнительные квитанции `type-names`, `collection-type-names` и
`collection-russian-type` фиксируют имена для `Тип()`. Ссылка допускает
`ТочкаМаршрутаБизнесПроцессаСсылка.<имя>` и
`BusinessProcessRoutePointRef.<имя>`. Полное имя коллекции —
`ТочкиМаршрутаБизнесПроцесса` / `BusinessProcessRoutePoints`;
короткие `ТочкиМаршрута` и `RoutePoints` как строки типа отвергаются,
хотя это имена свойства менеджера.

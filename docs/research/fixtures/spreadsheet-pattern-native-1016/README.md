# Тип узора табличного документа

Оригинальный BUH после декларации макета менеджера завершился на ТипУзораТабличногоДокумента.БезУзора в Отчет.РегламентированныйОтчетУСН.МодульОбъекта. Нативный контроль выполнен на 1С 8.3.27.2342 в отдельной файловой базе: load0, enterprise0, completed=YES. Девять выражений подтверждают RU/EN имена и регистронезависимость, идентичность значения, представление No pattern и имя типа SpreadsheetDocumentPatternType.

Текущий объём — только достигнутый член БезУзора / WithoutPattern. Остальные узоры и присваивание свойства рисунка не реализуются и не заявляются проверенными этим изменением. Исходная форма до пробы сохранена отдельно. Рабочие базы не изменялись.

Первое сквозное сравнение private CLI выявило расхождение только двух строк метатипа, сохранённое в private-cli-initial-mismatch.json. Исправленный candidate.patch задаёт EnumSpreadsheetDocumentPatternType через прежнюю таблицу метатипов; отдельный тест теперь проверяет и это имя. Это пока проверка временной копии, не доказательство изменения основного дерева или успешного запуска сеанса.

Окончательный вариант внесён в основное дерево после завершения предыдущих проверок. Focused runtime test прошёл. Private CLI с исправленным метатипом совпал со всеми девятью нативными выражениями в обычном и оптимизированном режиме; receipt и оба вывода сохранены. Полный прогон основного workspace выполняется отдельно.

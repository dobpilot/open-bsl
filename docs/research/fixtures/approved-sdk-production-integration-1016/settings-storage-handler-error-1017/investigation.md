# Диагностика ошибки обработчика загрузки

2026-10-17, 1С 8.3.27.2342. Повторён существующий `measure-handler-error.bsl` в новой собственной файловой базе `/tmp/open-bsl-settings-handler-investigation-1017-ib`. Исходники обработчика и измерительного скрипта не менялись.

У процесса Enterprise PID 873536 подтверждён аргумент именно этой базы. Через `_NET_WM_PID` выбраны только два окна этого процесса; снимки других приложений не делались.

После четырёх обычных вызовов появляется диалог с текстом `settings-load-probe`, `Further operation is only possible after restart. If the error persists, contact technical support.` и кнопками Restart / Finalize. Снимок: `native-fatal-dialog.png`. Внешняя пара Попытка/Исключение не вывела ни caught, ни missed до появления диалога. Это свидетельство критической ошибки в данном контексте, а не доказательство её обычной передачи вызывающему BSL-коду. Кнопки не нажимались; исход запуска проверяется отдельно по timeout.

Принятое требование `Handler errors SHALL propagate to the caller` и текущий обычный путь ошибки нельзя объявить нативно подтверждёнными этим результатом. До решения о контракте хоста маркер и запись открытого вопроса сохраняются. Runtime, спецификация и старые тесты не менялись.

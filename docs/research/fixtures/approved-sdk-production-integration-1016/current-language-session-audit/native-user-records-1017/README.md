# Парные нативные записи пользователей

Официальный ibcmd 8.3.27.2342 выгрузил собственную файловую базу завершённого трёхпрофильного контроля native-selected-language-1017 в languages.dt и восстановил её в одноразовый Postgres Pro Enterprise 18.6. Сырой SELECT v8users выполнен после успешного restore. Кластер остановлен, каталог удалён в finally. Рабочие базы не использовались.

Публичный decode_user_data SDK 0.9.21 декодирует четыре именованных записи: полные имена Native <имя> совпадают с нативными ПолноеИмяПользователя(). Для измеренной формы из 38 полей Atom с нулевым индексом 6 содержит UUID English/Русского либо nil при отсутствии выбора. UUID совпадают с метаданными нативного контроля. probe.rs проверяет все четыре записи существующим парсером SDK; выпускной декодер не менялся.

Все пользователи тестовые с пустыми паролями; DT/Data содержат только собственные данные. Дополнительная пустая запись v8users сохранена в users.json, но не подменяет именованные контроли. Другие формы записи, неизвестные значения и полный Session DB-путь этим результатом не проверены.

Неуспешные попытки с неверным окончанием порта и C locale сохранены отдельно; их серверы также остановлены и удалены. Успешный кластер использует en_US.utf8. Диагностический example-симлинк удалён; Cargo.toml не менялся.

Есть основание для ограниченного измеренного приобретения языка SDK и для закрытия вопроса полного имени вместе с постоянной регрессионной фикстурой. В режиме исследования исходники, маркеры и спецификация не изменены.

# Ссылка нового документа

Измерено 2026-10-02 на 1С 8.3.27.2342 в отдельной файловой базе `/tmp/open-bsl-document-new-reference-096`, русская локаль. Скрипт `measure-document-new-reference.bsl` и его `.platform.txt` сохраняют 21 наблюдение; `document-new-reference-module.bsl` проверяет доступ в теле модуля. Документы не записываются, исходные demo/buh/unf не меняются.

`ПолучитьСсылкуНового / GetNewObjectRef` сначала возвращает пустую ссылку своего документа с нулевым UUID. `УстановитьСсылкуНового / SetNewObjectRef` принимает пустую или заполненную ссылку того же документа. После назначения будущая ссылка меняется, а `Ссылка` самого нового объекта остаётся пустой. Другой экземпляр не наследует назначение.

Неопределено, Null, число, строка, булево, UUID, массив, сам объект, ссылки чужого документа и ссылка справочника отвергаются; прежнее назначение сохраняется. В теле модуля до завершения создания оба метода отвергают вызов. Полученный после создания тип сравнивается именно с `ДокументСсылка.ЗамерДокумента`: оставшийся в первоначальном шаблоне тип справочника был исправлен, затем эталон повторно снят на платформе.

Реплей всех 21 строк проходит через фасад в двух независимых сеансах. Используются существующие значения конфигурационных ссылок; проверка владельца и конфигурации разделяется с реализацией справочника. Его два существующих теста прошли без изменения ожиданий. Поведение записанного документа, проверка уникальности при записи и сами операции записи этой пробой не установлены.

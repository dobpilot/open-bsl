# Разделение данных текущего пользователя при запуске UNF

Read-only исходный UNF достиг чтения ПользователиИнформационнойБазы.ТекущийПользователь().РазделениеДанных.Количество() в СеансЗапущенБезРазделителей. Изолированная диагностика подтвердила получателя ПользовательИнформационнойБазы; это отдельное свойство, не metadata CommonAttribute.DataSeparation.

Нативные собственные файловые контроли сохранены в tests/conformance/measure/1c/measure-infobase-user-data-separation{,-values}.{bsl,platform.txt} и measure-current-user-separation-snapshot.{bsl,platform.txt}. Контроль именованного аутентифицированного ControlAdministrator дополнительно сохранён в fixtures/user-data-separation-named. Они подтверждают Structure, известную пустоту, чтение собственного строкового разделителя и изменяемую структуру, которую разделяют чтения того же пользовательского объекта. Следующий ТекущийПользователь() возвращает исходный снимок. Первые контроли без пользователей не использовались как единственное доказательство поведения аутентифицированного пользователя.

После strict validation support-reached-user-data-separation Principal получил optional SerializedValueGraph, задаваемый with_data_separation. BSL-свойство materialize один раз на каждый объект пользователя, удерживая изменяемую структуру только в этом объекте. Principal остаётся неизменяемым снимком, отдельные объекты и State не делят materialized структуру. Один корень Structure обязателен; неизвестность вызывает явный отказ, а не пустоту. Четыре целевых unit-теста прошли. Старые тесты не менялись. Справочник перегенерирован; целевой all-target Clippy прошёл.

Изменение поддерживает только достигнутое чтение свойства и мутацию возвращённой структуры. Ранее выбранное read-only ограничение записи свойств пользователя остаётся; редактирование пользователей и запись в базу не добавлены. SDK пока не предоставляет acquired граф: оригинальный UNF не прошёл эту границу, неизвестные данные не подменены. Запросы SDK и собственного физического замера: docs/plans/open-sdbl-user-data-separation-request.md и docs/plans/own-user-storage-native-measurement.md. Прямой автономный запуск и старые тестовые патчи ожидают отдельного согласования.

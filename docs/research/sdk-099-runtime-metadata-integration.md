Проверенная SDK-ветка — `feat/runtime-object-metadata-0.9.9`, реализация `1e8af74`, архив `ab0e44a`. Версия open-sdbl/open-sdbl-db в Cargo.lock open-bsl — 0.9.9. Main SDK не изменялся и пакет не публиковался.

`bsl-config-db/src/document_attributes.rs` проецирует приобретённые собственные реквизиты и части бизнес-процессов, настройки номера и стандартную политику проверки; для регистров накопления — вид, измерения и ресурсы. Типы, квалификаторы, синонимы, проверка и графы заполнения проходят существующий проектор реквизита. Второго декодера Config нет. `None` не заменяется пустым списком. Описатели владельцев сохраняются при проходе, повторного полного поиска для каждого бизнес-процесса нет.

Новые внешние тесты — `crates/bsl-config-db/src/runtime_object_projection_tests.rs`. Четыре теста проверяют собственные нативные артефакты SDK и прежние артефакты open-bsl: порядок членов, пустую часть, пустой оборотный регистр, оба вида регистров, строковый/числовой номер, неизвестность и квалификаторы. Контроли заполнения (21 строка) и обязательного реквизита (6 строк) исполняются с приобретёнными метаданными и сравниваются с полными нативными квитанциями. Язык конфигурации и язык системы заданы явно.

Сквозной контроль сначала отказал при создании объекта: SDK сохраняет строковые квалификаторы `[12, 1]`, а ранние ручные контроли использовали `[12]`. Нативная XML задаёт длину 12, AllowedLength=Variable; Config содержит `S,12,1`. Проверка формы объекта и проверка обязательной строки теперь принимают оба представления этой измеренной формы. Другие комбинации этим исправлением не объявлены поддержанными. После исправления весь нативный контроль совпал. Логи диагностики — `/tmp/open-bsl-sdk099-filling-diagnostic.log`, успешных контролей — `/tmp/open-bsl-sdk099-projection-controls.log`.

Проверки после изменения: адаптер/ORM/сеансы — 48 итогов target, 744 passed, 1 failed, 0 ignored (`/tmp/open-bsl-sdk099-runtime-final-tests.log`). Единственный отказ — прежний information_register_factories; ожидание не изменялось. Workspace Clippy all-targets с запретом предупреждений прошёл за 12.27 с, rustdoc — за 8.59 с. Полный workspace-прогон завершён отдельно: 456 итогов target, 3232 passed, 3 failed, 1 ignored; код 101, лог `/tmp/open-bsl-sdk099-workspace-tests.log`. Все conformance-проверки прошли.

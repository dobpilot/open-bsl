# Поиск значения в списке при инициализации demo

Исходный demo после исправления доступа к режиму совместимости достигает
`СписокЗначений.НайтиПоЗначению`, отсутствовавшего в таблице методов.
Синтакс-помощник 8.3.27.2342 подтверждает один обязательный произвольный
аргумент и результат — существующий элемент либо `Неопределено`.
Прямой нативный контроль сохранён в `fixtures/value-list-find-by-value/`.
Получены все 16 строк, включая границы: первая копия числа, идентичность
элемента, разные скалярные типы, регистр строк, пустые значения, тождество
массива и порядок после вставки.

Метод добавлен в существующую таблицу компонента. Он использует равенство
`BslValue`, просматривает текущий порядок и возвращает прежний дескриптор
элемента. Список не изменяется. Новый механизм VM и дублирующий builtin
не введены; зависимостей нет.

Два внешних unit-теста прошли. Тест потребителя использует только фасад,
проверяет оба языка, регистр и точный отказ арности при нуле/двух аргументах.
Полный native script через CLI побайтово совпал с oracle. Clippy runtime
и потребителя для всех целей прошёл. Справочник перегенерирован; новая строка
метода имеет арность 1. Старые тесты не изменялись.

OpenSpec `support-reached-value-list-find-by-value` строго провалидирован
до реализации. Повторный исходный demo и полный workspace-прогон ещё
предстоят; существующий тестовый патч сеанса и хеша остаётся на согласовании.

Повтор исходного demo завершился с кодом 1 за 145,02 с. Метод поиска
пройден; следующий отказ — декодирование значения константы
`ПрофильБезопасностиИнформационнойБазы`. Лог —
`target/diagnostics/readonly-startup/demo-value-list-find-1013-startup.log`.
Наблюдаемый пик RSS 7 141 272 КиБ. Инициализация ещё не завершена.

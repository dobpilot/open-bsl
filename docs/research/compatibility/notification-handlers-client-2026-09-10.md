## Свидетельство

Клиент серверной `localhost/test`, Linux, 1С 8.3.27.2342, 2026-09-10.
Прямой запуск `1cv8`, без Unica. Сессия
`/tmp/open-bsl-notification-handlers-cWvts4` завершилась с кодом 0:
свежие CF/XML сохранены до изменения, компиляция проверена, конфигурация
восстановлена и повторная XML-выгрузка побайтно совпала, кроме ConfigDumpInfo.xml.

- [Сценарий](../../../tests/conformance/measure/filesystem/notification-handlers.bsl).
- [Оригинальные 34 строки](../../../tests/conformance/measure/filesystem/notification-handlers.platform.txt), BOM/CRLF сохранены.
- SHA-256 сценария: `8f7c0095b00a2e65d4246df2d1e8e90ef20d0bfb78d355581e93cbbb3523d1c9`.
- SHA-256 вывода: `376b0081db02f56e7b7eca28b40cb40d39bfbd51262d20401ce60fd6e7c6d72e`.

Четырнадцать вариантов имени проверены дважды: как основной обработчик
двухаргументного конструктора (`.1`) и как обработчик ошибки пятой формы
(`.2`). Описания только создаются; обработчики не запускаются.

## Что проверяет конструктор

| Обработчик | Обе роли |
|---|---|
| Экспортные процедуры с 0, 1, 2, 3 параметрами | Приняты |
| Экспортная процедура с обязательным первым и необязательным вторым параметром | Принята |
| Экспортная функция с двумя параметрами | Принята |
| Экспортная асинхронная функция с двумя параметрами | Принята |
| Неэкспортная процедура и неэкспортная функция | Отказ: экспортный метод не найден |
| Имя в верхнем регистре | Принято, написание сохранено |
| Имя с пробелами по краям | Отказ: экспортный метод не найден, пробелы сохранены |
| Число 123 | Поиск экспортного метода с именем `123`, затем отказ |

Пустая строка и Неопределено в основной роли дают несовпадение типа
параметра 1, в роли ошибки — недопустимое значение параметра 4.
Конструктор не применяет правила конкретного файлового callback к числу
параметров, не запрещает функцию вместо процедуры и не запрещает async.
Это **не** доказывает, что все такие обработчики можно успешно вызвать
для любой операции. Доставка и создание — разные проверки.

В контексте этой клиентской управляемой формы `ЭтотОбъект`, `ThisObject`,
`ЭтаФорма` и `ThisForm` равны. Это не означает, что CLI обязан изображать
управляемую форму: представление текущего BSL-модуля в CLI/embedding остаётся
архитектурной задачей, и тип формы не должен выдаваться за измеренный тип
скриптового модуля.

## Следствие для реализации

При создании требуется регистронезависимый поиск экспортного имени без
обрезания пробелов, с сохранением исходного имени в свойстве описания.
Нельзя преждевременно отвергать найденный метод по арности или по признаку
функции/async. Сведения о модуле должны позволять именно проверку экспорта,
а не поиск любой локальной функции по строке.

В текущем open-bsl конструктор и ссылки текущего модуля отсутствуют;
сценарий завершается с пойманными отказами. Совпадение с oracle не достигнуто.
Остаются прямые вызовы, серверные обработчики, другие объекты в роли модуля,
ошибки при доставке и время жизни ссылок. Версия 8.5 и другие контексты
этой пробой не измерены. Rust-код в этом этапе не менялся.

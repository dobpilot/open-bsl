# Мобильные методы `Файл` вне мобильного контекста

Прямой замер выполнен на 1С 8.3.27.2342 в тонком клиенте серверной базы
`/S localhost/test` на Linux. Использован путь `content://open-bsl-probe`;
файловый ввод-вывод не выполнялся.

Платформа распознаёт RU/EN-имена четырёх членов:

- `ПолучитьПредставлениеФайлаБиблиотекиМобильногоУстройства` — арность 0;
- `ПолучитьКартинкуПредставленияФайлаБиблиотекиМобильногоУстройства` — арность 0;
- соответствующий метод `Асинх` — арность 0;
- Begin-форма получения картинки — арность **1**, а не 0, как следовало
  из первоначальной инвентаризации страницы справки.

Все корректные по арности вызовы в этом немобильном контексте дают ошибку
непосредственно. Async-форма не возвращает обещание. Begin без аргумента
получает ошибку недостатка параметров, с двумя — избытка; один
`Неопределено` проходит проверку арности и затем получает ошибку контекста.

open-bsl теперь публикует эти имена и арности в общем дескрипторе `Файл` и
возвращает ловимую ошибку контекста без обращения к host. Успешное поведение
мобильной библиотеки не моделируется: для него нужны отдельная возможность
host и тип `Картинка`. Это явно сохранено как `FILE.MOBILE_LIBRARY`.

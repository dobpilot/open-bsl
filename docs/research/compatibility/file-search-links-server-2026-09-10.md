# Первый замер поиска по символическим ссылкам

1С 8.3.27.2342, Linux, серверный модуль формы `/S localhost/test`.
Литеральный CompatibilityMode — Version8_3_27; effective-режим отдельно
не проверялся, 8.5 не измерялась. Unica не использовалась.

## Подготовленное дерево

Все объекты принадлежат отдельной сессии
`/tmp/open-bsl-find-links-qqNElD/tree`. Проба только читает их.
Обычные файлы содержат соответственно `direct\n`, `remote\n`, `leaf\n`.
Цели всех ссылок, включая отсутствующую, находятся внутри этого дерева.

```text
tree/
  root/
    actual/direct.txt
    linked-dir -> ../outside
    linked-file.txt -> ../outside/remote.txt
    broken.txt -> ../absent
  outside/
    remote.txt
    nested/leaf.txt
```

Дерево оставлено для контрольных проб; исходник содержит абсолютный путь
этой сессии. Для повторения на другой машине требуется подготовить такое
же изолированное дерево и явно изменить КореньСсылок. Это измеритель,
не переносимый conformance fixture и не сканирование системного temp.

## Результат и граница вывода

Позднейшие [контрольные деревья](file-search-link-controls-server-2026-09-10.md)
отделили следование по существующей ссылке от аномалии оборванной ссылки.
Ниже сохранены исходные результаты и ограничения первого замера.

| Проба | Серверная 1С | open-bsl |
|---|---|---|
| `root`, `*`, без рекурсии | 0 | 4 |
| `root`, `*`, с рекурсией | 0 | 5 |
| `root`, `*.txt`, с рекурсией | 2 ссылки: broken.txt, linked-file.txt | те же 2 и actual/direct.txt |
| `root/linked-dir`, `*`, с рекурсией | remote.txt, nested, nested/leaf.txt | совпало |
| Прямая ссылка на каталог или файл, пустая маска | сама ссылка | совпало |
| Оборванная ссылка, пустая маска | пустой массив | совпало |

Метаданные также совпали: существующие ссылки отражают тип цели,
Размер ссылки на файл — 7, Размер каталога вызывает ошибку. Для оборванной
ссылки Существует — Ложь, ЭтоФайл/ЭтоКаталог/Размер вызывают ошибки.

Нули для `*` в смешанном дереве пока **не объяснены**. Нельзя по этому
выводу заключить, что 1С всегда игнорирует ссылки, всегда следует по ним
или обязана возвращать пустой массив при любой оборванной ссылке.
Нужны независимые контрольные деревья: без ссылок, только ссылка на файл,
только ссылка на каталог, только оборванная ссылка и сочетания без неё.
Также требуется проверить влияние порядка элементов. FIND.TRAVERSAL
остаётся открытым; алгоритм runtime по этому первому замеру не изменён.

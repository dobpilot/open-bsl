# Виды host-объектов и ошибки metadata объекта `Файл`

Измерение выполнено напрямую на серверной `localhost/test`, Linux,
1С 8.3.27.2342. Unica не использовалась. Для платформы placeholder корня
был заменён на `/tmp/open-bsl-file-host-edges.cm4gyQ`. Финальная сессия
`/tmp/open-bsl-server-measure-uqaii6ux` завершилась с кодом 0, восстановила
CF и БД; контрольная XML-выгрузка совпала с исходной.

- Канонический исходник: `file-object-host-edges.bsl`, SHA-256
  `27b6b0f267f59d014b69bcef51fa135bf4b6b12b679d96cd99f2ff5529741d09`.
- Исполненный исходник с подставленным корнем: SHA-256
  `5e793ffc5f63bb2b3a425cb2b4dba983cd33b196433582376eb0a9f69c2fc1f8`.
- Oracle: `file-object-host-edges.platform.txt`, SHA-256
  `a66be0b1086a38b1e9a24e28731c51840b8c065e09e21d42c9ca1189b6125f10`.
- Снимок дерева: `file-object-host-edges.host.txt`, SHA-256
  `94059c47369437b8c8c71dc4d6832e0a12d12e39b2ed13283cb43b3ac5c39760`.

Внешнее дерево содержит пустой обычный файл, каталог, FIFO, Unix-сокет,
оборванную и самоссылочную ссылку, обычный файл как промежуточный компонент
и каталог с правами `000`. Случай `ENAMETOOLONG` построен компонентом из
300 байт. Для девяти путей проверены `Существует`, `ЭтоФайл`, `ЭтоКаталог` и `Размер`;
для восьми корневых форм сохранены все пять лексических свойств.

Обычный файл и каталог подтвердили прежние правила. FIFO и Unix-сокет
серверная 1С считает файлами, не каталогами, и возвращает их размер metadata —
ноль. Первый прогон без сокета (`/tmp/open-bsl-server-measure-29z_9c_m`)
выявил FIFO; финальный прогон измерил сокет и отверг прежнюю политику
open-bsl, считавшую его иным объектом. `SystemFileSystem` теперь распознаёт
только измеренные `FileTypeExt::is_fifo()` и `is_socket()`; остальные
специальные Unix-виды не обобщаются.

Для оборванной ссылки `Существует` уже возвращал Ложь. Новое наблюдение:
тот же результат получается для Linux `ELOOP`, `ENOTDIR`, `ENAMETOOLONG` и
`PermissionDenied`, тогда как три остальных метода во всех этих случаях
вызывают исключение. Runtime скрывает только эти измеренные категории;
произвольная `Other`-ошибка host по-прежнему передаётся вызывающему.

Пустая строка, `.`, `./`, `..` и `../` дают пять пустых свойств. `/`, `//`
и `///` сохраняют точное число разделителей одновременно в `ПолноеИмя` и
`Путь`, при пустых имени, основе и расширении. Текущая нормализация уже
совпадала с этой частью.

После исправления полный oracle совпадает в source/bytecode ×
plain/optimize. Unit-тест проверяет точный список скрываемых ошибок, а
системный тест вне sandbox проверяет FIFO и Unix-сокет. Прочие классы ошибок,
другие специальные объекты и I/O-конструкторы остаются
`НЕ ИЗМЕРЕНО(FILE.EDGE_BEHAVIOR)`.

# СоздатьКаталог: подготовленная проба, отказ лицензии

Обновление 2026-09-16: после активации лицензии пользователем измерения
возобновлены. [Результаты и исправление](file-create-paths-server-2026-09-16.md).
Ниже сохранена история отказов, а не текущий блокер.

## Объём и критерий

[file-create-paths.bsl](../../../tests/conformance/measure/filesystem/file-create-paths.bsl)
содержит 27 проб: RU/EN, повторные и смешанные разделители, точки и родители,
обычный файл в конечном/промежуточном компоненте, специальные символы,
процедура в выражении, лишний аргумент и три пустых значения. Непустой
путь строится только внутри нового временного корня. Контрольный обычный
файл имеет размер 3; результат содержит отсортированные имена потомков.
Сортировка нужна для исключения различий порядка перечисления из проверки
создания. Числа и коллекции не передаются: их возможное преобразование
в относительное имя могло бы создать каталог вне частного дерева.

Критерий — полный платформенный вывод без file.setup_error/file.cleanup_error,
восстановление CF/конфигурации БД и совпадение XML, затем сопоставление всех
результатов с open-bsl. Только после этого допускаются delta и исправление
поведения. Это продолжение активного extend-filesystem-operations; новый
контракт пока не принят и реализация не менялась.

## Две завершённые попытки

Кластер 8.3.27.2342 работает от kan, порты 1540/1541 слушаются; перед
прогоном клиента 1cv8 не было. Unica не использовалась. Команда:

```sh
python3 tests/conformance/measure/1c/run-on-server-1c.py \
  tests/conformance/measure/filesystem/file-create-paths.bsl \
  --marker create-paths-1 --allow-config-mutation --server-user kan
```

1. `/tmp/open-bsl-server-measure-4qpveyq8`: DumpCfg и первая XML-выгрузка
   успешны; повторная выгрузка перед загрузкой получила код 1 и
   «License not found. Software protection key or acquired software license not found!».
   Свежие original.cf и original-xml сохранены. XML содержит
   CompatibilityMode=Version8_3_27; effective-контекст пробы не получен.
2. `/tmp/open-bsl-server-measure-okbta9of`: уже DumpCfg получил код 1 и
   «License not found on the 1C:Enterprise server. Software protection key or acquired software license not found!».
   Новая копия CF не создана.

Оба runner завершились кодом 1 **до LoadConfigFromFiles**. Измерительная
конфигурация не загружалась, восстановления не требовалось. Это новый
лицензионный отказ, не повтор прежнего Connection refused. Причина
недоступности лицензии по этим сообщениям не установлена; лицензии,
службы и настройки кластера не изменялись.

Последующие read-only проверки в
`/tmp/open-bsl-license-check-ZujX6a` и
`/tmp/open-bsl-license-recheck-i9oMEd` также завершились кодом 1 на DumpCfg
с тем же серверным License not found; CF не создан. Запускалась только
резервная выгрузка, не полный измеритель. Незавершённых клиентов перед
этими проверками не было; ragent продолжает работать. Повторные проверки
не сняли блокер и не дали новых результатов о семантике BSL.

## Проверка open-bsl и ограничения

Скрипт компилируется и завершается с кодом 0, но четыре случая с обратной
косой чертой дают file.setup_error при последующем поиске: host вернул имя
элемента с путём. Это **не успешный замер** и не доказательство расхождения
с 1С. Предварительный вывод — `/tmp/open-bsl-create-paths-before.log`.
Критерий требует проверки побочных файловых эффектов, а не только кода
возврата процесса.

Платформенного oracle для этой пробы нет; `.platform.txt` и `.expected`
не создавались. Общий platform.tsv, реестр и маркер
CREATEDIR.PATH_SEMANTICS сохранены без изменения. Следующий шаг — повтор
той же команды после восстановления доступности серверной лицензии.

Регрессионные проверки прошли: cargo test --workspace, fmt, Clippy и rustdoc
с запретом предупреждений, git diff --check и 11 строгих проверок OpenSpec.
Логи — `/tmp/open-bsl-create-paths-{workspace,clippy,doc}.log`.
Общий conformance не обходит подкаталог measure/filesystem и не проверяет
эту новую пробу; её отдельный запуск выше остаётся неподтверждённым платформой.
Конфиденциальный корпус table_compare2 без переменной окружения не исполняется;
игнорируемая выгрузка MXL не является проверкой oracle.

# Тождество ИнициализироватьАсинх

1С 8.3.27.2342, клиент серверной `/S localhost/test`, напрямую без Unica.
Пробы меняют только объекты относительных путей и не создают файлы.

После двух вызовов с `beta/b.txt` и `gamma/c.bin` до ожидания оба обещания
возвращают объект с путём `gamma/c.bin`. Каждый результат равен исходному
Файл; независимый Файл того же пути не равен ему. Инициализация первого
результата путём `delta/d.dat` сразу видна исходному объекту и псевдониму.
Повторное ожидание первого обещания также видит `delta/d.dat`, не снимок `beta/b.txt`.
Путь, имя, основа имени и расширение после изменения согласованы.

Булево, Null, Дата и Массив приняты; их путь совпал со Строка аргумента
в той же сессии. Конкретные представления зависят от языка: здесь это
`Yes`, пустая строка, `1/2/2020 3:04:05 AM` и `Массив`.
Предыдущая [проба записи](file-async-write-client-2026-09-10.md) покрывает
строку, число, Неопределено, нормализацию и отказ вызову без аргумента.

## Реализация

Общее состояние пути имеет стабильный identity_key, независимый от текста.
Инициализатор меняет поля до возврата готового обещания. Он использует
сохранённый разделитель, без фонового доступа и файлового I/O. Регистрация
готового значения направляется внешнему владельцу динамического вызова;
BslValue не переносится в поток. Отказ исполнителя не меняет путь.

Остальные классы аргументов и ошибки представления остаются в
`НЕ ИЗМЕРЕНО(FILE.INIT_ARGUMENTS)` с записью реестра и отдельной measure-строкой.
Конструктор Файл этим изменением не расширяется: его граничные аргументы
остаются в FILE.EDGE_BEHAVIOR.

Позднейшая [серверная проба конструктора](file-constructor-server-2026-09-10.md)
подтвердила его необязательный аргумент и преобразование основных типов;
соответствующие ограничения конструктора затем исправлены отдельно.

Конформанс `file_initialize_async` получен из оригинального вывода:
для локализуемых представлений сохранено проверенное равенство пути
Строка аргумента и пути приёмника, а не зафиксирован язык сеанса.
Тесты host проверили отсутствие background_access и повторного чтения
разделителя, вложенные динамические вызовы, стабильность ключа Соответствие,
отказ без исполнителя обещаний без мутации, а также сохранение прежнего пути
у начатого metadata-запроса после переинициализации объекта.
Полный workspace, Clippy, rustdoc, fmt, API reference, реестр измерений и
строгий OpenSpec прошли.

# Покрытие интерфейса `Файл` платформенными пробами

## Решение

Один `file-object.bsl` не может корректно измерить весь интерфейс: синхронные
методы выполняются на сервере, методы `Асинх` и `Начать` требуют клиентского
контекста, а четыре метода библиотеки мобильного устройства доступны только
в мобильном контексте. Поэтому полнота фиксируется набором специализированных
проб, а начальный серверный сценарий остаётся проверкой конструктора,
свойств и основных синхронных операций.

## Карта проб

| Область | Платформенные исходники |
|---|---|
| Конструктор, RU/EN-свойства, базовые синхронные методы | `file-object.bsl`, `file-constructor.bsl` |
| Методы `Асинх`, чтение и запись метаданных | `file-async-client.bsl`, `file-async-read.bsl`, `file-async-write.bsl` |
| Методы `Начать` и доставка оповещений | `file-callback-methods.bsl` |
| Мобильные методы | `file-mobile-methods-client.bsl` |

Граничные значения и ошибки распределены по отдельным матрицам
`file-constructor-more-types`, `file-object-io-edges`, `file-attributes`,
`file-attribute-arguments`, `file-times`, `file-time-string-arguments` и
семейству `file-begin-*`. Наличие имени в наборе не доказывает полноту его
семантических границ: незакрытые случаи по-прежнему отмечены задачами и
маркерами `FILE.*`.

## Автоматическая проверка

Тест `every_file_member_name_occurs_in_the_platform_probe_suite` обходит
единственные таблицы `METHODS` и `PROPERTIES` в `bsl-rt` и требует, чтобы
каждое русское и английское имя встречалось хотя бы в одном исходнике выше.
Так новый член интерфейса не сможет появиться в runtime без платформенной
пробы. Арность и вид вызова независимо проверяет существующий
`the_complete_file_method_inventory_keeps_names_arities_and_call_kinds`.

Дополненный `file-object.bsl` измерен 2026-09-18 на серверной 1С
`localhost/test`, платформа 8.3.27.2342. Сессия
`/tmp/open-bsl-server-measure-7vtf50b2` завершилась строкой `RESTORED`, CF
восстановлен, XML совпал с исходным снимком кроме `ConfigDumpInfo.xml`.
Сырой oracle сохранён в `file-object.platform.txt`.

# Асинхронное чтение метаданных Файл

Измерено напрямую на 1С 8.3.27.2342, клиенте серверной базы `/S localhost/test`.
Unica не использовалась. 48 проб: восемь методов, RU/EN и обычный файл,
каталог, отсутствующий путь. Собственное временное дерево удалено скриптом.

Все вызовы вернули Promise. Для отсутствующего пути СуществуетАсинх дал Ложь,
остальные семь методов — ошибку при Ждать. Размер каталога также дал ошибку
при Ждать. Успешные результаты побочно сравнены с синхронными методами:
во всех 32 успешных пробах `sync_equal=1`. Обычный файл имеет размер 3;
файл и каталог имеют readonly=false, hidden=false. Время задано как
2020-01-02 03:04:05 UTC: универсальный результат совпал с ним, локальный
получился 2020-01-02 06:04:05. Это не измерение остальных временных зон,
диапазонов дат, ошибок доступа, гонок и неверных арностей.

- [Исходник](../../../tests/conformance/measure/filesystem/file-async-read.bsl), SHA-256 `3ae84e46852ab1b352feb4d3d4b6e542e6a2d3d1bf2f6c6c4c155a1d4d705c35`.
- [Оригинальный вывод](../../../tests/conformance/measure/filesystem/file-async-read.platform.txt), SHA-256 `f680bbef6cf4184991a433f5a66d2c54e7dfab01aed8a030d5650713cc995d0d`.
- Сессия `/tmp/open-bsl-file-async-read-VzMeIq`: свежие CF/XML до загрузки,
  восстановление CF после пробы, побайтовая сверка XML кроме ConfigDumpInfo.xml,
  runner завершился с кодом 0.

Предварительный прогон open-bsl сохранился в `open-bsl-before.txt` сессии:
все 48 вызовов отказали до обещания из-за отсутствующих методов. Этот вывод
служит воспроизведением неполноты реализации, а не oracle платформы.

## Реализация и проверка

Восемь методов подключены к общей таблице обещаний. Синхронное и асинхронное
чтение используют один преобразователь метаданных; фоновый поток передаёт
только метаданные/ошибку, локальная дата формируется в VM с зоной объекта.
В conformance `file_metadata_async` ожидаемые строки получены нормализацией
оригинального вывода: локальная дата обозначена `<local>` и сравнивается
с синхронной, язык имени типа и нестабильный временный путь в ошибках исключены.
Тип обещания проверяется самим скриптом. Все 48 строк совпали.

Тесты host проверяют задержанное чтение каждого RU/EN-метода, динамические
вызовы, повторное ожидание и фиксированную зону +03:00. Пул с одним worker
проверен с задержанным metadata: короткое задание завершается раньше,
отмена не ждёт файлового I/O. Проверены неизвестные атрибуты, отсутствие
фонового доступа и кооперативная отмена до/после metadata.
Полный workspace, Clippy, rustdoc, fmt, API reference и OpenSpec прошли.

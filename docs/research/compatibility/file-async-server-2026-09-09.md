# Файловые Асинх-методы на сервере 1С

1С 8.3.27.2342, `/S localhost/test`, пустые учётные данные, управляемая форма,
процедура `&НаСервере`. Выражения исполняются через `Вычислить` в `Попытка`;
в вывод включены описание ошибки и описание непосредственной причины.

Все 13 проб завершились ошибкой вызова с причиной
`Asynchronous methods are available only on the client`:

- `НайтиФайлыАсинх` и `FindFilesAsync` для существующего `/tmp`;
- поиск отсутствующего пути и поиск с явно переданным Неопределено вместо рекурсии;
- `СуществуетАсинх`, `ЭтоФайлАсинх`, `ЭтоКаталогАсинх`, `РазмерАсинх`;
- `ПолучитьТолькоЧтениеАсинх`, `ПолучитьНевидимостьАсинх`;
- `ПолучитьВремяИзмененияАсинх`, `ПолучитьУниверсальноеВремяИзмененияАсинх`;
- `КаталогВременныхФайловАсинх`.

Имена распознаны платформой: это не ошибка отсутствующего метода.
Для поиска даже ошибочный параметр рекурсии не изменил полученную причину.
Проба не устанавливает порядок всех проверок аргументов и не проверяет
`Ждать` на сервере. Она опровергает вывод о фактической серверной доступности
НайтиФайлыАсинх из одной лишь инвентаризации справки в этом контексте.

Полный асинхронный интерфейс остаётся в плане: для его успешной реализации
нужны клиентские измерения и явное описание контекста open-bsl. Нельзя
выдать серверный отказ за реализацию обещаний, требуемых согласованным объёмом.

# Объект Файл: первые серверные измерения

## Контекст и воспроизводимость

Прямой запуск 1С без Unica, с явным разрешением пользователя изменять
`localhost/test`. Измерения выполнены 2026-09-09 на Linux x86-64,
платформа `8.3.27.2342` (подтверждена `ibcmd --version`). В исходном и
восстановленном XML `CompatibilityMode=Version8_3_27`. Код выполнялся в
серверных процедурах управляемой формы; клиент только открывал форму.
Эффективная совместимость, часовой пояс и рабочий каталог отдельно из
исполняющего сеанса пока не выведены. Строковое представление типов и
булевых значений в этой сессии английское; сырой вывод не переведён.

- [Исходник проб](../../../tests/conformance/measure/filesystem/file-object.bsl),
  SHA-256 `448ad78e83f66fd2eef35532abbc1f8c6838cb459a407bf6d09176e0ac121ce4`.
- [Сырой результат 1С](../../../tests/conformance/measure/filesystem/file-object.platform.txt),
  SHA-256 `5f11f544b34eb18985de0b6ab5c27bc90b8349e5ae3bbf716aa46e2cbc0b3157`.
- Локальная сессия: `/tmp/open-bsl-files-approved-rBiijg`, включая CF,
  исходный, измерительный и восстановленный XML, обёртку запуска и логи.

Генератор `gen-form-module.py` перенёс объявления и тело в серверные
процедуры и заменил приёмник `Сообщить` записью в файл. Измеритель дошёл
до `file.end`, без `file.setup_error`, `refresh.error` и ошибки очистки.
Собственный scratch-каталог после прогона отсутствует.

## Измеренные различия

| Проба | Фактический результат 1С |
|---|---|
| Отсутствующий путь: Существует | Ложь |
| Отсутствующий путь: ЭтоФайл, ЭтоКаталог, Размер | Каждый метод вызывает исключение |
| Каталог: Существует, ЭтоКаталог | Истина |
| Каталог: ЭтоФайл | Ложь |
| Каталог: Размер | Исключение |
| Один объект до создания / после создания / после удаления | Ложь / Истина / Ложь |
| Размер через тот же объект после перезаписи | Меняется с 1 на 5 |
| Файл с тремя байтами UTF-8 без BOM | Размер 3 |
| Установка и чтение времени в локальном и UTC-варианте | Обе проверки равенства успешны |
| Установка невидимости обычному файлу на Linux | Исключения нет; ПолучитьНевидимость остаётся Ложь |
| Установка и снятие ТолькоЧтение | Истина, затем Ложь |

Проверенные пути также различают нормализацию от получения абсолютного пути:
`ПолноеИмя` для `каталог/имя.tar.gz` остаётся относительным;
`каталог/../имя.txt` становится `имя.txt`. Обратный разделитель в
`каталог\имя.txt` распознаётся, свойство `Путь` возвращает `каталог/`.
У `.hidden` пустое `ИмяБезРасширения`, расширение `.hidden`. Для
`каталог/` имя равно `каталог`, а `Путь` пуст. Эти примеры не устанавливают
контракт всех сочетаний точек, корней, разделителей или Windows-путей.

На момент этого сравнения open-bsl перехватывал отсутствие конструктора `Файл` во всех
пробах путей, затем отсутствие `СоздатьКаталог` при подготовке. До
файловых проб он не доходил. Поэтому совпадение завершающего маркера
показывает лишь работоспособность оболочки, а не совместимость методов.

## Сохранность базы и границы результата

Перед загрузкой отдельными командами сохранены свежие CF и XML. После
исполнения восстановлен CF, выполнена новая XML-выгрузка и `diff -r`
с исключением только `ConfigDumpInfo.xml`. Отличий нет; сценарий завершился
с кодом 0 и строкой `RESTORED: XML byte-identical except ConfigDumpInfo.xml`.
Это проверка конфигурационных исходников, не побайтное сравнение всей ИБ.

Результат ещё не покрывает неверные аргументы, ссылки, ограничения доступа,
полный диапазон времени и атрибутов, асинхронность, поиск, удаление по маске,
временные расширения и сроки очистки. Пробы времени проверяют round-trip,
но не доказывают смещение часового пояса. Ошибки пока сохраняют верхнее
описание; вложенные причины требуют дополнительных проб. Реестр вопросов
и `.expected` не изменялись, новых BSL-методов этот замер сам по себе не добавляет.

## Дополнение 2026-09-18

Начальная проба дополнена английским конструктором `File` и английскими
именами всех пяти свойств. Серверная 1С подтвердила те же значения, что и
для русских имён. Актуальные SHA-256:

- исходник: `3f2aedf6a582c74cdf267cd45e241b3ae17901e35f7ceba8a135e78cea68e007`;
- сырой результат: `a9f8ab95d0cac25f19364a8f2c707a9a85ccf1bcefb5efc28d6699af295fff6c`.

Успешная сессия `/tmp/open-bsl-server-measure-7vtf50b2` дошла до `file.end`,
восстановила CF и подтвердила совпадение XML с исходным снимком, кроме
`ConfigDumpInfo.xml`. Предшествующий запуск был оборван внешним исполнителем
после загрузки CF; резервная копия из его каталога была загружена вручную,
`UpdateDBCfg` повторён до чистого лога, а XML также побайтно сверен до нового
измерения. Полнота имён всего интерфейса теперь проверяется отдельным
[отчётом о наборе проб](file-interface-probe-coverage-2026-09-18.md).

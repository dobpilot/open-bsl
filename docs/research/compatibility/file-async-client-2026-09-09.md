# Файловые обещания на клиенте 1С

1С 8.3.27.2342, клиент серверной базы `/S localhost/test`, пустые учётные
данные. Генератор разместил асинхронные методы в клиентском модуле формы.
Пробы ожидаются последовательно. Вывод передаётся серверному приёмнику.
Файлы: собственный каталог `/tmp/open-bsl-file-async-client-8t9Juv/fixtures`,
`a.txt` содержит `abc` и LF (4 байта), `b.txt` — `def` и LF.

## Успешные результаты

Все вызовы возвращают значение типа Promise до `Ждать`.

| Вызов | Результат Ждать |
| --- | --- |
| НайтиФайлыАсинх, сам каталог без маски | Массив из одного Файл |
| НайтиФайлыАсинх / FindFilesAsync, маска *.txt | Массив из двух Файл |
| НайтиФайлыАсинх, отсутствующий путь | Пустой массив |
| СуществуетАсинх / ЭтоФайлАсинх для a.txt | Истина |
| ЭтоКаталогАсинх для a.txt | Ложь |
| РазмерАсинх для a.txt | Число 4 |
| ПолучитьТолькоЧтениеАсинх / ПолучитьНевидимостьАсинх | Ложь |
| ПолучитьВремяИзмененияАсинх / ПолучитьУниверсальноеВремяИзмененияАсинх | Дата (значение даты не записывалось) |
| ИнициализироватьАсинх с путём b.txt | Файл с именем b.txt |
| КаталогВременныхФайловАсинх | Строка (содержимое не записывалось) |

ИнициализироватьАсинх проверялся на Файл, уже созданном с путём a.txt.
Проба устанавливает возвращаемое имя, но не идентичность объектов или
изменение пути исходного объекта. Порядок элементов массива не записывался.

## Граница ошибки

НайтиФайлыАсинх с явным Неопределено в третьей позиции возвращает Promise
без исключения. Ошибка появляется у `Ждать`; непосредственная причина —
`Type mismatch (parameter number '3')`. Следовательно, синхронную проверку
этого аргумента нельзя просто вынести перед созданием BSL-обещания.
Это не доказательство порядка всех возможных ошибок, арностей и аргументов.

В [серверной пробе](file-async-server-2026-09-09.md) те же имена отвергаются
из-за контекста. Клиентский контракт не выдаётся за серверную доступность.

# Ссылки с особым именем `sfile` в файловом поиске

Измерение выполнено напрямую на серверной `localhost/test`, Linux,
1С 8.3.27.2342. Unica не использовалась. Во время платформенного запуска
placeholder корня был заменён на `/tmp/open-bsl-sfile-links.ihPOdF`.
Финальная сессия `/tmp/open-bsl-server-measure-41z26t5m` завершилась с
кодом 0, восстановила CF и БД; контрольная XML-выгрузка совпала с исходной.

- Канонический исходник: `file-search-sfile-links.bsl`, SHA-256
  `f9c763f8f0380a88682c7fe162d1d006e7dc04dd653052479e3c0d327b4a00e9`.
- Исполненный исходник с подставленным корнем: SHA-256
  `26f7f51b2e3e9526ee0efd542986a2f7aa3f2fb17da71d77f69be7576b197b55`.
- Oracle: `file-search-sfile-links.platform.txt`, SHA-256
  `b22bf482dd9139dd57d6b87399bbe27115e3dfe1a707dfde3a53ef1c05bee92a`.
- Нормализованный снимок дерева: `file-search-sfile-links.host.txt`, SHA-256
  `f9ead5dd3f244179f63517dfa16b9f2873e5c74a8761c07b59c2443e5e2a86bf`.

В трёх изолированных каталогах имя `a*` было ссылкой соответственно на
внешний каталог с `deep.txt`, внешний файл и отсутствующую цель. Для каждого
вида проверены четыре маски без рекурсии, три с рекурсией и прямой поиск пути.
Всего сохранено 24 результата плюс маркеры начала и конца.

Все три вида ссылки ведут себя одинаково. Точная, экранированная и
вопросительная маски возвращают специальный объект
`sfile://sfile://a*`; `Существует()` у него даёт Ложь, а `ЭтоКаталог()` —
ошибку. Маска `*` не выбирает объект, прямой путь без маски пуст.
Рекурсивный поиск не входит в целевой каталог ссылки и не выдаёт `deep.txt`.
Состояние цели и оборванность ссылки не меняют наблюдаемый результат.

Текущая реализация уже совпадала с этой матрицей после исправления запрета
спуска в специальный каталог. Добавлены host-тест трёх видов metadata и
точная проверка oracle в source/bytecode × plain/optimize. Первый успешный
сеанс `/tmp/open-bsl-server-measure-4yctjaoe` дал тот же структурный
результат с локализованным `No`; финальный измеритель выводит `0/1`, поэтому
oracle остаётся сырым и не требует постобработки. Другие имена и сочетания
`sfile`, циклы и классы ошибок остаются `НЕ ИЗМЕРЕНО(FIND.TRAVERSAL)`.

# Дополнительные типы маски асинхронного удаления

17 сентября 2026 года на Linux, платформе 1С 8.3.27.2342 и тонком клиенте
серверной базы `/S localhost/test` проверены десять дополнительных типов
маски `УдалитьФайлыАсинх/DeleteFilesAsync`. Эффективный режим совместимости —
`НеИспользовать`; Unica не использовалась.

Для девяти типов — Соответствие, двух фиксированных коллекций, таблицы
значений, UUID, Файл, двоичных данных, системного перечисления и Типа — файл
был назван безопасным строковым представлением значения. После `Ждать` он
удалён, корневой каталог сохранён, результат равен Неопределено. Дата также
принята без ошибки, но проверялась на несовпадающем контрольном имени из-за
зависимого от локали представления; файл остался. Все десять строк open-bsl
совпали с oracle после удаления технической строки контекста.

Сессия `/tmp/open-bsl-server-measure-ikuy0_df` восстановила CF и конфигурацию
БД; XML совпал полностью, кроме служебного корневого `ConfigDumpInfo.xml`.

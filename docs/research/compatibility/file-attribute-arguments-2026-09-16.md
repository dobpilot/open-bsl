# Аргументы файловых атрибутов: не всякое условие является Булево

## Контур и восстановление

1С 8.3.27.2342, Linux, серверная `/S localhost/test`, кластер от kan.
Синхронные setter измерены в серверном модуле формы, асинхронные — отдельно
в тонком клиенте той же базы. Native-запуски без Unica. В обоих XML
CompatibilityMode=Version8_3_27, эффективный режим из Метаданные —
НеИспользовать. Версия 8.5, файловая база и Windows не измерялись.

Сессии `/tmp/open-bsl-server-measure-npwl5wzu` (sync) и
`/tmp/open-bsl-server-measure-klxt4a5e` (async) завершились кодом 0.
Перед каждой загрузкой сохранены свежие CF/XML и проверена неизменность
конфигурации. После пробы восстановлены CF и конфигурация БД; XML совпал,
кроме корневого ConfigDumpInfo.xml. Резервные копии, логи и restoration.txt
сохранены. Обе пробы создают и удаляют собственный временный каталог с
одним трёхбайтовым файлом; рабочий каталог сервера не меняют.

Raw сохраняет BOM/CRLF и отдельные строки .detail с глубинной причиной

функция; это не наблюдение поведения async-процедур 1С.

## 448 случаев

Каждая серия: 28 значений × два setter × RU/EN × два начальных значения
только чтения = 224 случая, из них 128 успешных и 96 с отказом.
Перед каждым вызовом устанавливается исходное состояние; после проверяются
оба атрибута и размер. Async дополнительно проверяет стадию ошибки и
возврат Неопределено при успехе.

| Значения | Результат |
|---|---|
| Истина, Ложь; числа 0, 1, -1, 2, 0.1, -0.1 | Принимаются; ноль даёт Ложь, остальные измеренные числа — Истина |
| Строки Истина, Ложь, True, False, tRuE | Принимаются |
| Пробелы вокруг Истина, TAB вокруг False, NBSP вокруг True | Принимаются |
| Строки Да, Нет | Ошибка без изменения, не условные псевдонимы |
| Строки 1, 0, пустая, пробел, True<NUL>False | Ошибка без изменения |
| Неопределено, Null, массив, структура, дата | Ошибка без изменения |

Успешный SetHidden на этом Linux оставляет невидимость Ложь и не меняет
только чтение; имя файла не превращается в скрытое. Все ошибки сохраняют
оба атрибута, размер остаётся 3. Содержимое побайтно эта проба не сравнивает.
У async все 96 отказов приходят при Ждать, а не до возврата обещания;
все 128 успешных результатов — Неопределено.

## Расхождение и исправление

В прежнем open-bsl все четыре входа применяли as_condition. Он правильно
допускает Да/Нет в условии BSL, но для атрибута это приводило к лишнему
успеху и иногда меняло только чтение. Различались 16 случаев каждой серии.

Общий attribute_argument в bsl-rt/file отклоняет эти условные псевдонимы,
затем переиспользует общую конверсию остальных значений. Таблица булевых
слов не дублируется, поведение условий и другие параметры не меняются.
Async сохраняет ошибку подготовки через прежний update_async. На момент
этой пробы открытый вопрос и его измерительная строка были сохранены, а
маркер перенесён с двух setter в общий подготовитель. Последующие пробы
закрыли строковые представления и порядок относительно отказа доступа;
точная локализация относится к общей диагностике runtime.

## Проверки

CLI-тест file_attribute_arguments сначала воспроизвёл лишний успех и
изменение readonly для Да. После исправления все 448 результатов совпали
в plain, optimize и исполнении обоих текстовых листингов байткода.
Сравнение исключает только строку контекста и .detail: полные сообщения
сохранены в oracle, но их локализация/оформление не объявляются совпавшими.
Число строк, принятие аргумента, стадия async-ошибки и состояние не исключаются.

Unit-тест сохраняет прежнее значение Да/Нет в обычном условии. Host-тест
проверяет прямые и динамические RU/EN-вызовы с оптимизацией и без: setter
host не вызывается при отказе, async возвращает обещание с повторяемой
ошибкой ожидания. Это регрессия отказа без побочного действия, не отдельный
нативный замер повторного ожидания.

Полный cargo test --workspace прошёл, включая регрессию launcher, реестр
вопросов, API reference, сравнение plain/optimize и текстовый round-trip.
Также прошли fmt, Clippy --all-targets, rustdoc с запретом предупреждений,
git diff --check и все 11 строгих проверок OpenSpec. Логи —
/tmp/open-bsl-attribute-arguments-{test-red,test-after,unit,host,clippy,workspace,doc,openspec}.log.
Публичные имена, арности и формат байткода не менялись. Остальной файловый
план не объявлен завершённым и не архивирован.

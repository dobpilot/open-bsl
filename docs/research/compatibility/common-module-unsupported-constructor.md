# Неизвестный конструктор в общем модуле

Платформа 1С 8.3.27.2342, отдельные собственные файловые базы.
Контроль: `tests/conformance/measure/1c/measure-module-unknown-constructor-unused.bsl`
и `measure-module-unknown-constructor-lazy.bsl`. Штатный runner добавляет
в общий модуль `ЗамерыЛенивойАрности` соседний экспорт с
`Новый НеСуществующийТип()`; исправный экспорт остаётся прежним.

Контроль без обращения к модулю возвращает `UNUSED_START = OK` и
`UNUSED_END = OK`. Контроль с обращением даже к исправному экспорту
останавливается до его результата: внешняя `Попытка` не завершает пробу.
Частичный вывод `file.begin` не является успешно завершённым оракулом.
Повтор 2026-10-09 остановлен штатным тайм-аутом 45 секунд. Журнал собственной
базы `/tmp/open-bsl-unknown-constructor-called-1009-ib` записал:

```text
{CommonModule.ЗамерыЛенивойАрности.Module(31,16)}: Type is not defined (НеСуществующийТип)
```

Это ошибка компиляции всего модуля при первом обращении, а не ошибка
исполнения тела соседнего метода. Отдельный тест фасада проверяет
неиспользуемый модуль, обращение к исправному экспорту и сохранение
строгого режима для обычного запуска, закрытого и явного модулей.
Значения по умолчанию и операторы тела модуля этим контролем не измерены;
их обработка не расширяется.

# Составные относительные формы создания каталога

17 сентября 2026 года на Linux, платформе 1С 8.3.27.2342 и тонком клиенте
серверной базы `/S localhost/test` проверены двенадцать составных форм
`СоздатьКаталог` и `СоздатьКаталогАсинх`. Эффективный режим совместимости —
`НеИспользовать`; Unica не использовалась.

Формы `./.`, `././`, `.//`, `../.`, `.././`, `..//`, `./..`, `./../`,
`./../.`, `../../`, `/./` и `/../` успешно завершились синхронно. Асинхронный
метод во всех случаях вернул строку, дословно равную исходному аргументу.
Пути разрешаются только к существующим текущему каталогу, его родителям или
корню; проба не создаёт новых имён.

До исправления open-bsl отвергал первые десять форм: общий нормализатор
сворачивал их в пустой операционный путь. Измеренные формы теперь завершаются
как no-op до host, а Async создаёт готовое обещание исходного значения.
Точный список не обобщает результат на неизмеренные комбинации.

Сессия `/tmp/open-bsl-server-measure-6b62jnct` восстановила CF и конфигурацию
БД; XML совпал полностью, кроме служебного корневого `ConfigDumpInfo.xml`.

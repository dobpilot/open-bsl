# Удаление ссылок: платформа и защитная политика host

1С 8.3.27.2342, Linux, серверный модуль формы `/S localhost/test`.
Литеральный CompatibilityMode — Version8_3_27; effective-режим и 8.5
отдельно не измерялись. Unica не использовалась.

## Изолированные данные

Сессия `/tmp/open-bsl-delete-links-fDfotu` содержит независимые native и
openbsl деревья. До прогона openbsl получен копированием intact native;
ссылки относительные, поэтому цели каждой копии остаются в её пространстве.
18 случаев — девять видов удаления с первой и последней оборванной ссылкой.
Каждый случай имеет собственные root и outside:

```text
root/a.txt
root/actual/deep.txt
root/linked-dir -> ../outside
root/linked-file.txt -> ../outside/remote.txt
root/broken.txt -> ../absent
outside/remote.txt
outside/nested/leaf.txt
```

Порядок early (проверен ls -U): linked-file.txt, linked-dir, a.txt, actual,
broken.txt. В late broken.txt стоит первым, остальные записи в том же порядке.
Содержимое a.txt/deep.txt — direct с переводом строки, remote.txt — remote
с переводом строки, leaf.txt — leaf с переводом строки.

Измеритель содержит явный путь native. Локальная копия исходника меняет
только этот путь на openbsl. Для повторения нужно заново подготовить деревья:
проба деструктивна для этих тестовых данных и не должна повторяться на остатках.

## Результаты

Из 18 полных строк совпали 9. Наличие записи проверяется точной маской
НайтиФайлы, поэтому оборванная ссылка не путается с отсутствующим элементом.
Цели проверяются отдельно через Существует.

- Ссылка на обычный файл удаляется, цель сохраняется: совпало прямо и по маске.
- Ссылка на каталог: 1С удаляет содержимое цели, оставляет ссылку. open-bsl
  удаляет ссылку, сохраняя цель. Это верно для прямого вызова и точной маски.
  Внешняя проверка stat после обеих прямых проб подтвердила: outside остаётся
  каталогом, linked-dir остаётся символической ссылкой.
- Прямое удаление оборванной ссылки: 1С возвращает успех, но оставляет её;
  open-bsl удаляет. Точная маска broken.txt удаляет ссылку на обеих сторонах.
- Непустые маски выбирают те же элементы согласно измеренному порядку:
  late со * не меняет дерево; *.txt отличается для early/late как в поиске.
  Отличие эффекта удаления каталога-ссылки сохраняется для early со *.
- Пустая маска для root: 1С возвращает ошибку, оставляя root. В early часть
  записей и содержимое цели уже удалены; в late дерево не изменено. open-bsl
  удаляет root с его ссылками целиком и сохраняет outside.

Все удалённые файлы — сгенерированные данные этого scratch, восстанавливаемые
по описанию выше. Конфигурация восстановлена отдельно; восстановление CF
не означает восстановления файлов, намеренно удалённых измерителем.

## Решение требуется до изменения runtime

No-follow в SystemFileSystem::remove_path намеренный: комментарий прямо
фиксирует защиту от рекурсивного удаления чужого дерева. Принятый дизайн
сохраняет эту политику до отдельного решения. Поэтому результаты нельзя
автоматически превратить в удаление целей ссылок ради зелёного сравнения.
На момент отчёта у пользователя был запрошен выбор: сохранить защитное
отличие либо воспроизвести измеренную 1С-семантику через host. Пользователь
позднее сохранил no-follow; остальные аргументы и отказы закрыты последующими
измерениями и явным host-контрактом.

# Символические ссылки и пробельные имена в `НайтиФайлы`

## Контекст и сохранность

Измерение выполнено напрямую на серверной 1С 8.3.27.2342, Linux,
`/S localhost/test`, без Unica. Код исполнялся в серверном модуле формы;
`Метаданные.РежимСовместимости` вернул `НеИспользовать`. Клиентский и
асинхронный контексты, 8.5, ошибки доступа и циклы ссылок не измерялись.

Сессия `/tmp/open-bsl-server-measure-g44c7t7h` завершилась кодом 0.
Runner восстановил исходный CF; повторная XML-выгрузка совпала с исходной,
кроме служебного корневого `ConfigDumpInfo.xml`. Конфигурация и данные
пользователя в измеряемое дерево не входили.

Сценарий только читает отдельное дерево
`/tmp/open-bsl-find-link-spaces-Q7mP2a`. Обычные файлы пусты, ссылки ведут
либо на собственный каталог `targets/linked target`, либо на отсутствующий
`absent target`. Упорядоченный снимок дерева сохранён вместе с oracle.

- Сценарий: `file-search-link-spaces.bsl`, SHA-256
  `23381abb3e47f18338823b44443b9c4062468d28ca3008ac57228b86bcaed412`.
- Нативный вывод: `file-search-link-spaces.platform.txt`, SHA-256
  `f92659fe23e80f52bce3eb826d9049aaf631891dd7354cec774d45eea4ea3446`.
- Снимок дерева: `file-search-link-spaces.host.txt`, SHA-256
  `0e92381955f546767d10eed623385e0bf2d1067581d721635a0ac417490303a3`.

## Матрица и результат

Два дерева × восемь масок × плоский/рекурсивный режим × RU/EN дали
64 вызова. Проверены `*`, `*.*`, `*.txt`, `* *`, `space*`, `*dir`,
`broken*` и `[[:space:]]*`. Имена обычных каталогов, файлов, действующей
ссылки на каталог и оборванной ссылки содержат пробелы.

Все 64 упорядоченных результата серверной 1С совпали с open-bsl. В дереве,
где оборванная ссылка встречается до действующей, маска `*` возвращает ноль
и не начинает рекурсивный обход. При обратном порядке действующая ссылка
попадает в результат, а рекурсивный поиск возвращает её два дочерних файла.
Маска `* *` совпадает с пробелом внутри имени; POSIX-класс
`[[:space:]]*` требует пробельный символ в первой позиции и здесь не
совпадает. RU и EN дали одинаковые строки.

Это подтверждает уже реализованный порядок обработки для данной матрицы.
Результат не обобщается на `PermissionDenied`, циклы ссылок, остальные
маски и управляющие пробельные символы; `FIND.TRAVERSAL` остаётся открытым.

## Автоматическая проверка

`links_with_space_names_match_the_native_ordered_oracle` воспроизводит
снимок через детерминированную `FileSystem` и сверяет все 64 строки oracle.
Отдельный CLI-тест создаёт реальное дерево и сравнивает source/bytecode ×
plain/optimize. Оба целевых теста прошли. Runtime-код и публичный API этим
этапом не менялись.

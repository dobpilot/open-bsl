# Типы аргумента СоздатьКаталог на сервере

Дата замера: 2026-09-18. Платформа: 1С 8.3.27.2342, серверная база
`localhost/test`, пустая аутентификация. Не-async сценарий исполнялся
runner-ом в серверном методе управляемой формы; Unica не использовалась.

Для безопасности относительных имён измеритель до вызова проверяет отсутствие
конечного пути и первого компонента. Если любой из них существует, операция
пропускается. После вызова удаляется только ранее отсутствовавший первый
компонент. В принятом oracle нет ни `skip=preexisting`, ни `cleanup_error`.

Серверный результат совпал с клиентским правилом:

- 17 значений с непустым `Строка(значение)` успешно создают каталог именно
  этого представления: строка, число, оба Boolean, дата, массив, структура,
  соответствие, три фиксированные коллекции, ТаблицаЗначений, UUID, Файл,
  ДвоичныеДанные, элемент перечисления и Тип;
- пустой СписокЗначений, Неопределено и Null отказывают без создания;
- объект Файл создаёт буквальный каталог `Файл`, но не путь `inside`, который
  хранится внутри объекта.

Последний пункт исправляет трактовку `file-create-directory-roots`: та проба
доказала только отсутствие изменения внутреннего пути объекта и не наблюдала
каталог его строкового представления. Контекстного различия sync/async здесь
нет; async отличается возвратом исходного значения после успешного I/O.

Сеанс `/tmp/open-bsl-server-measure-ooksuden` восстановил CF/БД; XML совпал,
кроме ожидаемого служебного корневого `ConfigDumpInfo.xml`.

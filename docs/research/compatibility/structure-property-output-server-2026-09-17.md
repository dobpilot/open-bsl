# Выходной параметр `Структура.Свойство`

17 сентября 2026 года на серверной базе `localhost/test` прямым `1cv8`
8.3.27.2342, без Unica, измерена двухаргументная форма
`Структура/ФиксированнаяСтруктура.Свойство/Property`. Сессия
`/tmp/open-bsl-server-measure-zugc9wce` завершила восстановление CF/БД;
XML совпал с исходным, кроме корневого `ConfigDumpInfo.xml`.

Найденное поле возвращает `Истина` и записывает значение во второй аргумент.
Отсутствующее возвращает `Ложь` и записывает `Неопределено`, то есть прежнее
значение 99 не сохраняется. Правила одинаковы для RU/EN и обычной/фиксированной
структуры. Литерал во второй позиции допустим: метод возвращает `Истина`,
не требуя записываемой цели. Индекс массива является записываемой целью и
получает значение поля.

Сценарий: `13bf25f7610f28d6bbf6c904697ad75b8affb0c60c688062b6046e79dab83cb2`.
Oracle: `fcac1f382fae04ef922048e8ab04fca4f7d8dbb1d124d03b8fa0028ad3c78f52`.

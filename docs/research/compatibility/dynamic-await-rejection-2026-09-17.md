# Запрет Ждать внутри динамической строки

Исправлено 2026-09-17 по нативным пробам предыдущего этапа:
[контекст измерения и артефакты](dynamic-execution-2026-09-17.md).
Это клиент 8.3.27.2342 серверной localhost/test, не файловая база и не
отдельное измерение 8.5. Нового запуска платформы для этого исправления
не потребовалось; исходные oracle не менялись.

До исправления четыре наблюдения давали `ok|23`, `ok|23`, `error|11`,
`error|11` вместо платформенных `error|1`, `error|1`, `error|1`, `error|11`.
Причина — compile_dynamic_snippet выбирал async-резолвер по признаку
вызывающего кадра и переносил этот признак на фрагмент. Платформа его
не переносит: ошибка компиляции предшествует даже присваиванию, написанному
до Ждать. Уже выполненная запись внешнего фрагмента перед ошибкой вложенного
Вычислить сохраняется.

Обе ветви штатного компилятора, с реестром и без него, теперь используют
синхронное разрешение фрагмента. Чанк не получает is_async вызывающего.
DynamicRequest.caller_is_async сохранён как информация о вызывающем для
внешних компиляторов; публичные низкоуровневые async-резолверы сохранены
ради Rust-совместимости, но штатный динамический компилятор их не вызывает.
Статические async-функции, вызываемые из строки, не изменены: их обещания
по-прежнему можно возвращать и ожидать снаружи.

OpenSpec delta добавлена перед реализацией. Новых API, зависимостей и
версии формата нет. Маркеры/реестр неизмеренных вопросов не изменялись.

Проверки:

- Точные копии dynamic-async-await.bsl/platform.txt добавлены в conformance
  как dynamic_async_await.bsl/.expected, cmp подтвердил отсутствие изменений.
- Все четыре строки совпадают, включая отсутствие записи до отказа и
  сохранение внешней записи при ошибке вложенного выражения.
- 16 сочетаний RU/EN, Execute/Eval, async/sync caller, с/без реестра
  отвергаются резолвером; допустимые контрольные фрагменты не асинхронны.
- VM-вход без реестра и фасад с реестром проверены отдельно. Отказ
  фрагменту не портит исходное обещание: обычное Ждать возвращает 23.
- Прежние 18 наблюдений dynamic_async_context остаются зелёными.
- Прошли полный workspace с plain/optimize, round-trip, API reference и
  реестром измерений, Clippy all-targets и rustdoc с запретом предупреждений.
- Прошли fmt, diff check и все 11 строгих проверок OpenSpec.

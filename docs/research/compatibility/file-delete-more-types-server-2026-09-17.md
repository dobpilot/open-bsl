17 сентября 2026 года на серверной 1С 8.3.27.2342 `/S localhost/test`
проверены десять ранее не покрытых типов второго аргумента `УдалитьФайлы`:
Дата, Соответствие, ФиксированныйМассив, ФиксированнаяСтруктура,
ТаблицаЗначений, УникальныйИдентификатор, Файл, ДвоичныеДанные, значение
перечисления и Тип. Эффективный режим совместимости — `НеИспользовать`;
Unica не использовалась.

Каждый случай имел собственный временный `data/keep.bin`. Представление
маски не использовалось для построения пути, поэтому значение не могло
расширить область удаления. Все десять вызовов успешны, корень и
несовпадающий сосед сохранены. Это подтверждает принятие типов и применение
непустого строкового представления; точный локализованный текст каждого
представления не объявляется измеренным этим скриптом.

Сессия `/tmp/open-bsl-server-measure-w_nagvbj` восстановила CF и
конфигурацию БД; XML совпал полностью.

- Oracle SHA-256: `2a5d2ca17c5dd3dc635a873ba15a3a089fff217d9b43065531ac07bb4b19a993`.

Текущий общий BSL-форматировщик open-bsl уже соответствовал всем десяти
результатам; изменения runtime не потребовались. Oracle проверяется в
source/bytecode × plain/optimize. Последующие пробы закрыли частичный отказ,
а гонки определены контрактом одного снимка целей. Прочие поддерживаемые
значения используют общий `Строка` без отдельного файлового белого списка.

# Прямые вызовы через ссылку на модуль

Подключён следующий этап после [представления аргументов](open-call-arguments-2026-09-17.md).
Полный пункт прямых вызовов и доставка Begin ещё не завершены.

Дополнение: два расхождения живой видимости из таблицы ниже устранены
следующим этапом; его измерения и текущие ограничения описаны в
[отчёте модульных алиасов](module-aliases-2026-09-17.md).
Ниже сохранено состояние первого этапа прямых вызовов.

## Исполнение

VM определяет живого владельца ссылки среди текущего модуля, root и
сессионных экземпляров каталога. Ссылка завершённого запуска не воскрешает
его состояние. Экспорты, параметры и вид объявления берутся из Program
и Chunk; собственного каталога исполняемых методов у ссылки нет.
Арность, требование результата и глубина проверяются до продвижения pc.

Знач и аргументы-выражения получают собственные слоты: аргументное окно
оптимизатор может перенаправлять на локаль вызывающего. Знач использует
уже вычисленный аргумент даже при последующем изменении его переменной.
Локальные параметры без Знач сохраняют ссылку на исходный слот.
Модульные/импортированные параметры используют существующий механизм
записи при выходе из кадра; повторные модульные цели нового открытого вызова
делят один слот. Обнаруженная потеря записи при исключении исправлена общим
с нормальным возвратом помощником, включая обычный Call.

Async-метод создаёт обычную задачу со снимком аргументов. Холодный диспетчер
возвращает её номер в существующий StartAsync, который запускает ребёнка
до первого уступающего ожидания. Вложенный блокирующий драйвер не используется.
Изменений формата или новых BSL-имён на этом этапе нет; формат остаётся 31.

## Нативная проверка параметров

Проба [module-reference-arguments.bsl](../../../tests/conformance/measure/filesystem/module-reference-arguments.bsl)
исполнена на сервере 1С 8.3.27.2342 в localhost/test, пустые учётные данные,
без Unica. Это проверка обычных параметров BSL, не отождествление МодульBSL
с управляемой формой. Сессия `/tmp/open-bsl-server-measure-y31kkxa4` завершилась
с кодом 0: свежие CF/XML сохранены, CF и конфигурация БД восстановлены,
XML совпали кроме корневого ConfigDumpInfo.xml.
[Исходный вывод](../../../tests/conformance/measure/filesystem/module-reference-arguments.platform.txt)
сохранён побайтно;
общий platform.tsv не перезаписывался.

## Проверки и оставшийся объём

Первый тест был красным с UnknownMethod «Изменить» у МодульBSL. Отдельный
красный тест показал потерю записи модульного параметра при исключении.
Оба теперь проходят.

`crates/open-bsl/tests/module_calls.rs` проверяет source/bytecode ×
plain/optimize: экспорт/арность/контекст результата, умолчания, явное
Undefined, локальные алиасы, Знач и порядок аргументов, исключения,
глубину, общие модули, обратный вызов entry, повторные запуски и async.
VM отдельно проверяет отказ ссылке завершённого экземпляра.
Проверка файлового пула с одним worker расширена до 24 комбинаций:
обычный/объектный запуск, прямой/динамический I/O, поиск/чтение/запись,
завершение/отмена; соседнее задание не блокируется ожиданием.

Динамический синхронный вызов собственного метода проходит. Возвращаемое
из Вычислить BSL-обещание пока отвергается как принадлежащее другому запуску
(`/tmp/open-bsl-module-call-edges.bsl`, лог `open-bsl-module-calls-edges.log`).
Передача чужого каталожного контекста динамическому исполнителю ещё не
подключена. Эти случаи, живые модульные алиасы и доставка Begin не закрыты
проверками уже реализованной части.

Логи этапа: `/tmp/open-bsl-module-calls-{red,test,lifetime,worker,unwind-red,edges,platform,local-probe,clippy,workspace,doc,openspec}.log`.

Полный workspace, fmt, Clippy --workspace --all-targets и rustdoc с запретом
предупреждений прошли. После сохранения платформенного вывода добавлен
module_argument_exception с двумя подтверждёнными строками; повторно прошли
все пять проверок conformance, включая plain/optimize и bytecode round-trip,
а также обе проверки бандлов/устранения копий на полном корпусе.
API reference, реестр измерений, git diff --check и все 11 строгих проверок
OpenSpec прошли. Эти результаты не закрывают перечисленные расхождения.

# Оборванная ссылка между результатами поиска

1С 8.3.27.2342, Linux, серверный модуль формы `/S localhost/test`.
Литеральный CompatibilityMode — Version8_3_27; effective-режим и 8.5
отдельно не измерялись. Unica не использовалась.

## Подготовка

Scratch `/tmp/open-bsl-find-broken-middle-0lH2uH/tree` содержит три дерева.
Обычные файлы содержат `direct\n`; broken.txt указывает на отсутствующий
`../absent` внутри scratch. Порядок проверен `ls -U`:

- match: before.txt, broken.txt, after.txt, branch.txt;
- skip: before.bin, broken.txt, after.txt, branch.txt;
- dir: branch.txt, before.txt, broken.txt, after.txt.

В каждом branch.txt есть inner.txt. Проба только читает подготовленные данные.
Абсолютный путь в измерителе относится к этой сессии; перенос требует нового
изолированного дерева с явно проверенным порядком и замены КореньСсылок.

## 42 результата и вывод

Семь масок (*, *.*, *.txt, *.bin, b*, a*, broken.txt), три дерева,
рекурсия включена/выключена. Ошибок вызова нет, полный порядок путей сохранён.

- match с *.txt: только before.txt, без рекурсии в branch.txt.
- skip с *.txt: broken.txt, after.txt, branch.txt; без inner.txt.
- dir с * и рекурсией: branch.txt, before.txt, затем branch.txt/inner.txt.
- Во всех деревьях a* находит after.txt, точное broken.txt находит ссылку.
- * и *.* сохраняют лишь записи до оборванной ссылки; в dir сохраняется
  также рекурсивный обход уже выбранного branch.txt.

В совокупности с предыдущими первой/последней позициями это подтверждает
раздельное прерывание совпадений и списка каталогов. Первая совпавшая запись
обычной измеренной маски может быть оборванной ссылкой; последующая
совпавшая оборванная ссылка прекращает выдачу без включения себя.
Измеренные * и *.* такой первой ссылки не допускают. Выбранные до прерывания
каталоги обходятся, позднейшие — нет. Это описание наблюдаемого результата,
не утверждение о внутреннем алгоритме платформы.

## Исправление

Общий обход хранит два признака завершения на уровень и начало результатов
уровня. Только NotFound метаданных сообщённой host ссылки включает эти
правила; другие ошибки не подавляются. Фильтрация перед проверкой поздней
не совпавшей ссылки, иные маски/ошибки и несколько оборванных ссылок остаются
FIND.TRAVERSAL. Удаление использует общий выбор, но его дополнительные
эффекты на момент отчёта ещё требовали отдельных проб. Они закрыты серией
удаления ссылок, частичного отказа и явным контрактом снимка целей.

Все четыре исходных измерителя после изменения совпали с oracle:
file-search-links (19 строк), file-search-link-controls (24),
file-search-broken-masks (48), file-search-broken-middle (42), всего 133.
Добавлены десять детерминированных сценариев виртуального host с явным
порядком записей, включая отдельное прерывание списка каталогов.

Прошли 12 тестов файла find_files и полный `cargo test --workspace`, включая
ZIP, асинхронные операции, конформанс plain/optimize/round-trip и реестр
вопросов. Также прошли fmt, Clippy и rustdoc с `-D warnings`, строгий OpenSpec.
Полный журнал — `/tmp/open-bsl-search-broken-workspace.log`. Обычные
ограничения набора сохраняются: конфиденциальный корпус без
OPEN_BSL_TABLE_COMPARE2_CASES не запускается, игнорируемая выгрузка MXL
не считается платформенным сравнением.

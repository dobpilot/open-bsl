# Преобразования аргументов поиска на серверной 1С

Измеритель: `tests/conformance/measure/filesystem/file-search-types.bsl`;
сырой вывод: соседний `file-search-types.platform.txt`, BOM/CRLF сохранены.
1С 8.3.27.2342, Linux, `/S localhost/test`, серверный модуль формы.
Без Unica, с пустыми учётными данными. XML содержит Version8_3_27;
effective compatibility этим сеансом не проверялся. Версия 8.5 не измерена.

Сеанс `/tmp/open-bsl-find-types-approved-GFF32g`: перед загрузкой получены
свежие original.cf и original-xml. После замера CF восстановлен, XML
побайтно совпал кроме ConfigDumpInfo.xml, runner exit 0. Есть begin/end,
нет setup_error/cleanup_error.

SHA-256 скрипта: `1c3a5ac343770dad3a4ed8851b7649e87be2a8140842a3cb37ace0ab9badd15d`.
SHA-256 вывода: `2532e254d5f2a57e75fee376d974ada96700659fc03d00ffee21a2e8e3c7fb14`.

## Измерено

- Маски 17 и 0 находят существующие файлы 17 и 0; это не игнорирование типа.
- Массив как маска находит файл Массив. Null и Неопределено возвращают сам
  корневой каталог, как пустая/отсутствующая маска.
- Пропуск третьей позиции запятой выполняет нерекурсивный поиск.
  Пропуски обеих необязательных позиций возвращают сам каталог.
- Явные Неопределено, Null и пустая строка в рекурсии вызывают ошибку.
  -1 и строка Истина включают рекурсию.
- Булевы маски не нашли ни одного из подготовленных имён. В наборе нет
  Yes/No; точное представление и зависимость от языка этим не доказаны.
- Файл как первый аргумент вернул пустой массив, но это не доказывает,
  какое именно строковое представление пути использовано.

## Реализация и оставшиеся вопросы

Встроенный поиск получает существующий BSL-форматировщик из VM. Ни Rust
Display, ни второй алгоритм представления значений не используются.
Резолвер подставляет Ложь для отсутствующей или пропущенной запятой рекурсии,
но сохраняет явное Неопределено. Падающие тесты подтвердили старый TypeError
для числовой маски и ошибку для пропуска третьего аргумента.

На момент отчёта общий перенос строкового преобразования, локализация,
сложные числовые форматы и порядок ошибок оставались открытыми. Последующие
матрицы подтвердили общий `Строка`, все классы рекурсии и порядок до I/O;
локализация относится к общему форматированию. Conformance расширен
измеренными именами 17/Массив и двумя результатами для Null/пропуска.

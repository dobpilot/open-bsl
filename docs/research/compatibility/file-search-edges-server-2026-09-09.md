# Границы поиска на серверной 1С

Прямой запуск без Unica: 1С 8.3.27.2342, Linux, `/S localhost/test`,
пустые учётные данные. XML конфигурации содержит Version8_3_27; фактический
режим совместимости этим запуском отдельно не проверялся. Это серверный
модуль управляемой формы, не файловая база и не проверка версии 8.5.

Скрипт: `tests/conformance/measure/filesystem/file-search-edges.bsl`.
Сырой вывод: соседний `file-search-edges.platform.txt` (BOM/CRLF сохранены).
Сеанс: `/tmp/open-bsl-find-edges-approved-Zm6mr6`.
Свежие original.cf и original-xml сохранены до изменения. После выполнения
CF восстановлен, XML совпал побайтно, кроме ConfigDumpInfo.xml; runner exit 0.
Есть file.begin/file.end, ошибок setup/cleanup нет.

SHA-256 скрипта: `ffdb14dc1ae6ebc626513bb6594cb33a0f0d191b6c1e7724209c8d227dbb0d95`.
SHA-256 вывода: `2704d83d8799a6d768ea684ca397533fb31de1bae5a36ac389da23cfc10922ae`.

## Результаты и расхождения

| Проба | Серверная 1С | open-bsl до исправления |
|---|---|---|
| Маска * для отсутствующего пути, с рекурсией и без | Пустой массив | IoError |
| Маска * для обычного файла, с рекурсией и без | Пустой массив | IoError |
| Завершающий / в пути каталога | Найден a.txt | Совпадает |
| Явное Неопределено в аргументе рекурсии | Ошибка | Трактуется как Ложь |
| Рекурсия 0 / 1 / строка Ложь | 1 / 2 / 1 результата | Совпадает |
| Маска 17 | Пустой массив | TypeError |
| Путь 17 или Неопределено | Пустой массив | TypeError |
| Нет маски, рекурсия Истина | Сам каталог | Совпадает |

Пустой результат для числа пока не доказывает преобразование в строку:
нужна проба с существующим файлом `17` и другими типами. Поэтому нельзя
на основании этих нулей внедрять универсальную строковую конверсию.

Причина потери различия между отсутствующей рекурсией и явным Неопределено:
резолвер дополняет все необязательные позиции BuiltinFn значением Undefined.
Исправлению нужен измеренный default Ложь именно для отсутствующего третьего
аргумента НайтиФайлы; явное значение должно остаться отдельным случаем.
Пропуск позиции запятой требует дополнительной пробы, как и порядок ошибок.

Маски, ссылки, порядок результатов и ошибки доступа этим замером не закрыты.

## Исправление подтверждённой части

Корневые read_dir-ошибки NotFound и NotADirectory теперь дают пустой массив.
Остальные ошибки не подавляются; отдельный тест сохраняет PermissionDenied.
Резолвер подставляет Bool(false) только в отсутствующую третью позицию
НайтиФайлы, а runtime больше не считает явное Undefined значением по умолчанию.
Оба теста воспроизвели расхождения до исправления и прошли после него.
В conformance file_search добавлены четыре нулевых количества и факт ошибки
из этого oracle; текст локализованного сообщения об ошибке не сравнивается.
Числовые пути/маски и пропуски запятыми остаются открытыми.

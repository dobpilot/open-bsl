# Аргументы `ИнициализироватьАсинх`

Проверено на 1С 8.3.27.2342 в тонком клиенте серверной базы
`/S localhost/test`, напрямую. Проба не обращается к файловой системе:
она меняет только лексический путь объектов `Файл`.

Для структуры, соответствия, другого `Файл`, значения типа, системного
перечисления, двоичных данных, буфера двоичных данных, уникального
идентификатора и описания типов платформа показала единый контракт:

- вызов возвращает `Promise`;
- путь приёмника до `Ждать` уже равен `Строка(Аргумент)`;
- результат ожидания имеет тот же путь и тождествен приёмнику.

Вместе с прежними пробами строк, чисел, `Неопределено`, `Null`, булевых,
дат и массива это подтверждает алгоритмическое правило через `Строка`, а не
перечень частных преобразований. Реализация уже использовала общий formatter;
новый conformance закрепляет остальные доступные клиенту категории.

| Нет аргумента / Неопределено | `.tmp` |

| `xml` / `.xml` | `.xml` |
| `..tar.gz` | `..tar.gz` |
| `a/b` | `.a/b`, без исключения при выдаче имени |
| `a\b` | `.a\b`, без исключения при выдаче имени |
| Число 17 | Исключение |

`КаталогВременныхФайлов()` вернул `/tmp/` с завершающим разделителем.
Этот прогон не менял TEMP/TMP серверного процесса и не проверяет их приоритет.
Имя с разделителем не использовалось для записи: успех выдачи имени не
означает существования его родителей или возможности записи по нему.

В текущем open-bsl нет `.tmp` по умолчанию, суффикс `xml` присоединяется
без точки, а `a/b` вызывает ошибку при резервировании имени. Следовательно,
одной нормализации расширения недостаточно: нужно отдельно уточнить
host-контракт выдачи имени и сохранение его гарантий для пользовательской ФС.

## Создание, поиск и удаление

Повторное создание существующего каталога успешно; отсутствующие родители
`branch/leaf` создаются. Создание каталога по пути обычного файла вызывает
исключение. Другие ошибки доступа и аргументов здесь не проверялись.

Поиск без маски возвращает массив из самого существующего файла или
каталога; отсутствующий путь — пустой массив. Пустая маска и Неопределено
на пути каталога также возвращают сам каталог, не его содержимое.

В дереве с `a.txt`, `b.TXT`, `plain`, `.hidden`, `я.txt` и каталогом
`branch/leaf/deep.txt` наблюдались следующие различия:

- `*` включает скрытый файл, файл без расширения и подкаталог.
- `*.*` не включает `plain` и `branch`, но включает `.hidden`.
- `?.txt` нашёл только `a.txt`, не `я.txt`.
- `[a-z].*` нашёл `a.txt` и `b.TXT`.
- Рекурсивный `*.txt` нашёл `я.txt`, `a.txt` и вложенный `deep.txt`,
  но не `b.TXT`.

Случай `?` доказывает расхождение с посимвольным Unicode-сопоставителем ZIP
на данном наборе, но сам по себе не доказывает байтовую реализацию платформы
или независимость от локали. Нужны отдельные пробы многобайтных имён.
Порядок элементов сохранён в сыром выводе; один прогон не доказывает
сортировку или устойчивость этого порядка на других деревьях.

`УдалитьФайлы(корень, "*.txt")` удалил `a.txt` и `я.txt`, сохранив сам
корень, `b.TXT`, `plain`, `.hidden`, подкаталоги и вложенный `deep.txt`.
Рекурсивное перечисление после удаления зафиксировало оставшиеся объекты.
Удаление каталогов под маской, симлинков, read-only и частичные отказы
остаются незамеренны.

## Проверка прогона

Есть `file.begin` и `file.end`, нет ошибки подготовки или очистки.
Созданный scratch-каталог после прогона отсутствует. Обёртка завершилась
с кодом 0; CF восстановлен, повторный `diff -r` исходного и восстановленного
XML не показал различий, исключая служебный `ConfigDumpInfo.xml`.
Это не побайтная проверка данных всей ИБ.

В исходном сравнении оболочка в open-bsl достигла конца, но блок создания/поиска/удаления
был пропущен после ошибки отсутствующего `СоздатьКаталог`. Её успешное
завершение не считается прохождением этих проб. `.expected` и реестр вопросов
не менялись; новые BSL-методы ещё не реализованы.

Продолжение реализации: расширения временных имён приведены к измеренным
случаям. BSL-нормализация выполняется до вызова пользовательского host;
его суффикс остаётся дословным. Системный host резервирует первый компонент
имени, не создавая родителей суффикса. Тесты сохраняют отсутствие файла,
данные при коллизии и изоляцию виртуальной ФС. Поиск, удаление по маске
и жизненный цикл этим исправлением не закрываются.

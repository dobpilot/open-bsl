# Асинхронная запись атрибутов и инициализация Файл

Измерено напрямую на 1С 8.3.27.2342, клиенте серверной `/S localhost/test`,
без Unica. 36 проб: четыре setter с RU/EN на файле, каталоге и отсутствующем
пути; четыре setter с Неопределено; восемь вариантов инициализации.

## Запись атрибутов

Все setter вернули Promise. На файле и каталоге результат Ждать — Undefined.
ТолькоЧтение=Истина прочиталось обратно как Истина, Невидимость=Истина на
Linux — как Ложь. Локальная дата 2020-01-02 06:04:05 и универсальная
2020-01-02 03:04:05 прочитались соответствующими getter без изменения.
Для отсутствующего пути и аргумента Неопределено ошибки возникли при Ждать.
Типы вне проверенных Булево/Дата/Неопределено этим измерением не установлены.

## Инициализация

ИнициализироватьАсинх/InitializeAsync меняет ПолноеИмя исходного объекта
и его псевдонима до Ждать, уже при возврате обещания. Результат Ждать —
Файл с новым путём. Несуществующий путь принимается; `directory/../b/`
нормализуется в `b`. Пустая строка и Неопределено дают пустой путь,
число 123 — строку `123`. Без аргумента отказ происходит до обещания и
исходный путь остаётся прежним.

Это доказывает мутацию приёмника, но ещё не доказывает тождество возвращённого
объекта: нужны цепочка повторных инициализаций и проверка ссылочного равенства.
Инициализацию нельзя реализовать как фоновое создание независимого Файл.

Последующая [проба тождества](file-initialize-identity-client-2026-09-10.md)
подтвердила общий изменяемый объект и повторное ожидание; измеренный контракт
инициализации реализован отдельно от setters.

## Реализация setters

Четыре setter реализованы через FileMetadataUpdate и общий канал файловых
обещаний. Подготовка даты разделена с синхронным API; на момент пробы
неизвестные границы времени и аргументов атрибутов были сохранены. Фикстура
`file_attributes_async` содержит 28 setter-проб; ожидаемые строки получены
из исходного вывода удалением языка имени Undefined и текста ошибок,
при сохранении стадии отказа, результата и прочитанного значения атрибута.
Сам скрипт проверяет тип Promise/Обещание.

Тесты с управляемым host проверили RU/EN и динамический вызов, UTC-секунды
при зоне +03:00, повторное ожидание без второй записи, ошибку подготовки при
Ждать, отказ без background_access и отсутствие отката после отмены.
Пул с одним worker проверен для записи: короткое задание выполняется до
освобождения host, отмена не ждёт записи, уже выполненная запись сохраняется.
Полный workspace, Clippy, rustdoc, fmt, API reference, реестр измерений и
строгая проверка OpenSpec прошли. ИнициализироватьАсинх этим не закрыт.

## Измеренные 48 случаев

Девятнадцать индексов проверены через Вставить/Insert на исходном `[10, 20]`.
Дополнительно — шесть проверок арности, два вызова как выражения и две
вставки в пустой массив. Методы выполняются через Выполнить/Вычислить;
прямой вызов отдельно покрыт тестом реализации, не второй нативной пробой.

- 0 вставляет в начало, 1 — между элементами, 2 — в конец.
- 3 и 10 расширяют массив, заполняя промежуток Неопределено.
- 1.9, строки "1", " 1 ", "1.9" и Истина выбирают индекс 1.
- -0.9 и Ложь выбирают индекс 0; -1 и -1.9 отвергаются.
- "x", Неопределено, Null, массив и дата отвергаются без изменения.
- Один аргумент вставляет Неопределено; ноль и три аргумента отвергаются.
- Вызов как выражения отвергается до изменения массива.
- В пустом массиве индекс 2 даёт `[Неопределено, Неопределено, 99]`.

RU/EN совпали. До реализации open-bsl отклонял все вставки, поэтому
положительные случаи oracle образовали воспроизводимый падающий тест.
После реализации все 48 строк совпали. В fixture удалены только BOM/CRLF
и строка контекста вместе с её запросом; ожидания не получены из open-bsl.

## Реализация и границы

Обработчик добавлен в существующий BuiltinMethod::Insert. Подготовка индекса
переиспользует array_method_index; типизация индекса `[]` не меняется.
Полный объём памяти резервируется до resize/insert, чтобы отказ выделения
не оставлял частично изменённый массив. Это защита runtime, а не измеренный
предел 1С. Проверены невозможный размер i64::MAX, неверная арность/индекс,
сохранность данных, псевдоним массива и тождество вставленного объекта.

Insert в выражении получает открытый CallObjectMethod с result_required;
VM отвергает этот случай для массива до вызова обработчика. Insert как
оператор сохраняет прежний выбор пути, в том числе для структур и
соответствий. Формат байткода не менялся. Прямые вызовы, вызовы через
параметр, default значения и отказ выражению проверены с оптимизацией
и без неё; другие получатели проверены на отсутствие регрессии.

ARRAY.METHOD_INDEX остаётся открытым для прочих преобразований, диапазонов
и точных ошибок. Дополнительные измерения Insert не выдаются за замеры
Get/Set. Доставка Begin-callback, BSL-модуль как получатель и остальные
недостающие методы таблиц этим этапом не реализованы. Этот обработчик —
зависимость соответствующего незавершённого пункта файлового плана.

Итоговые проверки прошли: полный cargo test --workspace, включая общий
plain/optimize, текстовый round-trip и реестр вопросов; fmt --check,
Clippy --all-targets и rustdoc с -D warnings, регенерация API reference,
git diff --check и строгий OpenSpec (11 элементов). Формат и таблица
имён методов не расширялись. Полный файловый план не завершён.

# Проверка достижимости модулей объектов из внешнего кода

При новой пробе ссылочных реквизитов фабрика имела исходник модуля объекта документа и описатель with_object_module, но модуль сеанса содержал только пустую УстановкаПараметровСеанса. Вызов СоздатьДокумент из последующего Session::instantiate завершился ошибкой «Модуль конфигурации Документ.ЗамерДокумента.МодульОбъекта не найден». Тот же тестовый контракт, что у остальных проб документов, включает в модуль сеанса экспортную СоздатьПробу со статическим вызовом СоздатьДокумент; такой корень проверяется далее.

Отдельно исследовать, является ли это заявленной границей configuration_roots или недостающей загрузкой доступного исходника при динамическом вызове из внешнего кода. Не считать ошибку отсутствие исходника доказанной: он передан в ConfigurationCodeSnapshot. Не компилировать всю конфигурацию без исследования, не добавлять вторую реализацию BSL и не обходить единый источник кода. Исправление не включено в расширение типов реквизитов. Существующие ожидания тестов не менялись.

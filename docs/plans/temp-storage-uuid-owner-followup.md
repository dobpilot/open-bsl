# UUID во втором параметре временного хранилища

При декодировании исходного buh найден вызов
`ПоместитьВоВременноеХранилище(, Новый УникальныйИдентификатор)`.
Точная форма проверена на 8.3.27.2342: эталон
`tests/conformance/measure/1c/measure-native-image-external-function-hole.platform.txt`
подтверждает строковый адрес и чтение `Неопределено`.

Сейчас `crates/bsl-rt/src/temp_storage.rs` принимает во втором параметре
только строковый адрес или `Неопределено`; UUID получает ошибку типа.
Исправление декомпиляции сохраняет пропуск аргумента, но эту границу
runtime не закрывает. Перед реализацией нужны OpenSpec и измерение
повторного использования UUID и срока жизни связанного значения.
Не возвращать успешный результат без действующего хранилища.

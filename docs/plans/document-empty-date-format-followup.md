# Отдельное расхождение форматирования пустой даты

В первой нативной пробе собственных реквизитов документа выражение `Формат(ДатаПробы, "ДФ=yyyyMMddHHmmss")` при пустой дате вывело пустую строку на 1С 8.3.27.2342, а интерпретатор вывел `00010101000000`. Значения самих реквизитов совпали после явной проверки `ДатаПробы = Дата(1, 1, 1)` в одинаковом коде пробы для обеих сторон. Нативные пробы после этого изменения перезапущены на 1С, а весь workspace прошёл проверки; эталон не генерируется интерпретатором. Само расхождение форматирования остаётся открытым.

Исходный воспроизводящий результат теста: `document.primitives.initial=[No]:[00010101000000]` вместо нативного `document.primitives.initial=[No]:[]`; те же строки для Undefined/Null. Проверить отдельно текущую спецификацию форматирования, комментарии и историю bsl-format, затем измерить матрицу шаблонов и исправить в самостоятельном изменении при необходимости. Это замечание не устранено расширением типов реквизитов; существующие ожидания тестов не менялись.

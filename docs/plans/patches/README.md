# Подготовленные патчи интеграции сеанса

`open-sdbl-session-settings-1015.patch` — изменения поверх подготовленного SDK commit 2f0c5b0: приобретение строковых разделителей пользователя, общий декодер контейнера/настройки, scoped SQL чтения. Включает OpenSpec, тесты и собственные нативные фикстуры. Текущая версия включает измеренные строковый и числовой профили с состояниями Active/Inactive/ConditionDisabled. Этот отдельный патч не содержит UUID; совокупная ревизия с UUID описана ниже. Версия SDK не меняется, публикации нет. Итоговый SDK workspace после числовой ревизии: 978 passed, 0 failed, 13 ignored; fmt, Clippy, rustdoc и OpenSpec strict прошли. Патч проверен reverse-check против черновика.

Остальные патчи подготовлены для open-bsl и не применены к основному адаптеру: сначала логическая проекция и resolver, затем приобретённые разделители Principal и общий контейнер; последним — провайдер настроек и подключение CLI. У них общие места в data_access.rs: перед применением вместе нужно проверить/свести контекст, одиночные dry-run не доказывают совместную применимость. Текущая рабочая интеграция находится в /tmp/open-bsl-report-integration/open-bsl; её диагностические eprintln не должны попадать в основной код.

Ни один из этих патчей не означает успешного запуска оригинальной конфигурации. Новые ошибки и результаты находятся в docs/plans/configured-session-startup-current-failures.md. Исходный SDK checkout feat/extension-purpose-0.9.15 остаётся неизменным; main не менялся.

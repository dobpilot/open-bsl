# Документация open-bsl

Документация разделена по назначению. Путь отвечает на вопрос, насколько
документ нормативен и должен ли он описывать текущее состояние.

## Разделы

- [`architecture/`](architecture/) — действующие архитектурные решения и
  границы компонентов.
- [`reference/`](reference/) — справочная документация по языку, CLI и
  доступному BSL API.
- [`plans/`](plans/) — активные планы, у которых ещё остаётся работа.
- [`research/`](research/) — измерения, обратная разработка форматов и
  исследования производительности.
- [`archive/`](archive/) — завершённые или отменённые планы. Они объясняют
  историю решений, но не задают текущий контракт.

Проверяемые требования к поведению системы находятся отдельно в
[`openspec/`](../openspec/). Изменение начинается там с предложения и сценариев,
а после реализации попадает в основной набор спецификаций. Большой план в
`docs/plans/` уместен, когда важна последовательность исследований; контракт
наблюдаемого поведения всё равно формулируется в OpenSpec.

## Справочник BSL API

Запуск исходного модуля сеанса с подключением к базе описан в
[`reference/configuration-session-cli.md`](reference/configuration-session-cli.md).
Там приведены выбор тонкого или веб-сеанса, параметры подключения и границы
текущей реализации.
[Файловые источники XML и EDT](reference/configuration-file-sources.md) описывают
подключение локального кода и ресурсов при сохранении ORM и прав из БД.
Подготовка модулей и подробных метаданных при первом обращении описана в
[`architecture/on-demand-session-preparation.md`](architecture/on-demand-session-preparation.md).

Сводный справочник функций, конструкторов, объектов, методов и свойств
генерируется из runtime-дескрипторов:

```bash
cargo run -p bsl-cli -- --emit-api-reference
cargo run -p bsl-cli -- --emit-api-reference docs/reference/bsl-api/api.md
```

Файл [`reference/bsl-api/api.md`](reference/bsl-api/api.md) хранится в
репозитории как проверяемый снимок. Пояснения и примеры, которые нельзя
выразить дескриптором, следует класть рядом в `reference/bsl-api/`, а не
дублировать в них перечни имён и арностей.

## 3. Таблица в образе

Всплыло при реализации 2.1 и решается здесь: строки операторов ФРАГМЕНТА
`Выполнить`/`Вычислить` считаются от начала его собственного текста, а не
файла. Показывать их редактору как строки файла нельзя — он откроет не то
место. Решить явно: либо у чанка фрагмента таблица строк пуста, либо
фрагмент получает собственный источник. Молчаливого «пусть будет как
вышло» здесь быть не должно.

- [ ] 3.1 `Program::lines` и наблюдатель к ней; в `Chunk` поля не
  добавляются.
- [ ] 3.2 Кодогенератор заполняет таблицу, когда сведения запрошены.
- [ ] 3.3 `Chunk::local_names` заполняется у всех чанков при сведениях об
  отладке и по-прежнему только у `uses_dynamic` без них.
- [ ] 3.4 Запрос сведений — параметр сборки в `bsl-compiler` и в фасаде
  `open-bsl`.

## Дополнительные проверки границ

Сравнены тела 34 функций и шести типов из списка «Что НЕ трогаем»:
все совпадают с базой; список — [hot-core-source-checks.txt](hot-core-source-checks.txt).
Единственная правка тела `poll_linked` — замена тройного выбора
программы/линковки/кэшей на `CatalogContext::execution_parts`, предусмотренная
отдельным diff задачи 4.4. Это проверка исходников, не машинного кода.

`RunCaches` остаётся во владении запуска. Его создание и прогрев не
менялись; `catalog_caches` не слит с `ModuleInstance`. Два новых теста
проверяют выбор исходных ссылок по одному ключу и прежние ошибки таблиц.
Внутренняя видимость VM согласована владельцем и записана в design.

Полные последовательные ворота 5.1 пройдены: fmt, Clippy, build,
workspace test (1739 passed, 0 failed, 1 ignored), строгий rustdoc
и отдельный JIT-корпус. Отдельно прошли runtime smoke/registry и jobs smoke.
Оговорки окружения и пропуски перечислены в verification; окончательный
явный прогон контрактов выполняется задачей 5.4.

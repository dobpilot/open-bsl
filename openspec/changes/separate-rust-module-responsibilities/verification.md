Поведение и видимость не менялись.

После исправления все обязательные команды прошли повторно: fmt,
Clippy, build, workspace test (1730 passed, 0 failed, 1 ignored), строгий
rustdoc и отдельный JIT-корпус. Логи: `rustdoc-preparation-*.log`.

## 1.3. Публичные пути и layout

Добавлены интеграционные тесты `bsl-rt/tests/public_paths.rs` (3),
`bsl-vm/tests/public_paths.rs` (2) и `open-bsl/tests/job_public_paths.rs` (2).

trait-контракты. Проверка layout ограничена исходной платформой x86-64
Linux; на другие цели числовое утверждение не распространяется.

Целевые запуски всех семи тестов прошли. Исправлены две ошибки в новых
тестах до приёмки: `NameId` создаётся публичным `from_index`, а не через
закрытое поле; убран лишний `unwrap()` над литеральным `Ok`.
Полные ворота `step-1.3-*.log` прошли: fmt, Clippy, build,
workspace test (1737 passed, 0 failed, 1 ignored), строгий rustdoc,
отдельный JIT-корпус. Production-код на этом шаге не изменялся.

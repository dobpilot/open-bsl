# Журнал выполнения

## 1.1. Исходная версия

- Ветка: `bsl-rt-v4.3`; исходный HEAD: `408f4d5`.
- Перед началом рабочее дерево чистое. Единственный активный change —
  `separate-rust-module-responsibilities`; перекрывающихся изменений нет.
- `408f4d5` отличается от `59e7056` только документацией и OpenSpec.
  Для функциональных проверок исходная версия — `408f4d5`.
- Прочитаны `AGENTS.md`, proposal, design, tasks, delta и план VM.
- Среда: `rustc 1.97.1 (8bab26f4f 2026-07-14)`,
  `cargo 1.97.1 (c980f4866 2026-06-30)`.
- `OPEN_BSL_TABLE_COMPARE2_CASES` не задан: конфиденциальный набор не
  будет считаться исполненным по зелёному общему тесту.
- По границе поручения пункты 3.8, 4.7 и 5.6 остаются владельцу.
  Бенчмарки и машинные экраны не запускаются; суждений о
  производительности в этом журнале нет.
- Корневой `TASKS.md`, эталоны `.expected`, сгенерированный API reference,
  реестр открытых вопросов и измерительные скрипты не редактируются.

Полные логи проверок текущей сессии находятся в
`/tmp/open-bsl-module-refactor.zFAuBT/`; подтверждённые результаты и
сопоставление тестов фиксируются ниже по шагам.

## 1.2. Проверки базы

На исходной версии fmt, Clippy, build и полный workspace test прошли:
1730 passed, 0 failed, 1 ignored. Первый запуск тестов в песочнице
остановился на запрете локального HTTP-сокета; повторный с разрешёнными
сокетами завершился с кодом 0. Единственный явный ignore —
`dump_for_the_platform_crosscheck`, который готовит файлы для платформы.
Конфиденциальный `table_compare2` без переменной окружения не исполнялся.

Строгий rustdoc на `408f4d5` обнаружил публичную ссылку на приватный
`RunCaches` (`bsl-vm/src/lib.rs:2019`). Владелец разрешил отдельное
исправление: коммит `eaf715a` заменяет ссылку обычным кодовым выделением.
Поведение и видимость не менялись.

После исправления все обязательные команды прошли повторно: fmt,
Clippy, build, workspace test (1730 passed, 0 failed, 1 ignored), строгий
rustdoc и отдельный JIT-корпус. Логи: `rustdoc-preparation-*.log`.
Эти проверки относятся и к документальным коммитам 1.1/1.2: после
прогона исходники и состав тестов не менялись.

В `baseline-tests.txt` сохранён вывод инвентаризации `cargo test -p bsl-rt
-p bsl-vm -p open-bsl -- --list`: 672 зарегистрированных теста с
группировкой по исполняемым файлам. Инвентаризация не подменяет исполнение.
Layout исходной сборки x86-64 Linux, rustc 1.97.1:
`BslValue` — size 24, align 8; `RtError` — size 48, align 8.
Это локальная проверка представления, не обещание стабильного Rust ABI.

## 1.3. Публичные пути и layout

Добавлены интеграционные тесты `bsl-rt/tests/public_paths.rs` (3),
`bsl-vm/tests/public_paths.rs` (2) и `open-bsl/tests/job_public_paths.rs` (2).
Они используют только прежние публичные пути, проверяют сигнатуры
предметных методов, доступность интерфейсов VM/jobs и существующие
trait-контракты. Проверка layout ограничена исходной платформой x86-64
Linux; на другие цели числовое утверждение не распространяется.

Целевые запуски всех семи тестов прошли. Исправлены две ошибки в новых
тестах до приёмки: `NameId` создаётся публичным `from_index`, а не через
закрытое поле; убран лишний `unwrap()` над литеральным `Ok`.
Полные ворота `step-1.3-*.log` прошли: fmt, Clippy, build,
workspace test (1737 passed, 0 failed, 1 ignored), строгий rustdoc,
отдельный JIT-корпус. Production-код на этом шаге не изменялся.

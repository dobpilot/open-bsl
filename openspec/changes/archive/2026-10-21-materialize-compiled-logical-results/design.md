# Design
Current original receipts: demo-chart-empty-host-1013-startup.log and unf-storage-ref-1013-startup.log. The acquired demo constant declaration is B|S(120,1); SQL compiler emits Boolean, String and Binary TYPE cells. TypeValue::tag already names the measured platform tag protocol; TypeValue::decode takes five bytes and must not be used for the one-byte storage discriminator.

Use an exact SDK logical recipe over final physical column indices and requested logical names. Do not group by ColumnOrigin (repeated field occurrences share origin), parse labels (provider truncation), or inspect generated SQL. Decode only the active member through existing cell conversion; preserve reference metadata and inline storage acquisition. A complete recipe describes all selected logical columns; unavailable/ambiguous mapping fails explicitly, without a partial result or guessed first member.

The compiler retains SQL generation and access-control preparation. Host conversion validates row width, physical indices, discriminator length, tag and selected-member uniqueness. Null and Undefined alternatives must use SDK/native protocol evidence; do not manufacture false/empty string from an inactive filler. Binary and UUID composite shapes with ambiguous tag mappings remain explicitly unavailable. Scalar results preserve existing behavior. Implementation starts only after the SDK API is concretely available in an isolated validated draft.

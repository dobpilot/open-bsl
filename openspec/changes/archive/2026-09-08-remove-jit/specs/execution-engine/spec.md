# Delta: единый исполнительный контур

## ADDED Requirements

### Requirement: VM исполняет байт-код одним интерпретатором

`bsl-vm` SHALL исполнять `Program` интерпретатором и SHALL NOT предоставлять
режим компиляции байт-кода в машинный код. Публичные входы VM и фасада
SHALL NOT принимать выбор такого режима.

#### Scenario: Публичный Rust API

- **WHEN** host создаёт состояние `open-bsl` или запускает `bsl-vm`
- **THEN** API не требует и не предлагает параметр JIT

#### Scenario: Командная строка

- **WHEN** пользователь передаёт `--jit`
- **THEN** `bsl-cli` отвергает неизвестный ключ и завершает запуск с
  ненулевым кодом

### Requirement: Benchmark сравнивает проходы оптимизации

Общий benchmark SHALL показывать отдельные столбцы обычного `bsl-cli` и
`bsl-cli --optimize`. Оба прогона тяжёлого сценария SHALL участвовать в
побайтной проверке результата.

#### Scenario: Полный прогон benchmark

- **WHEN** запущен `benchmarks/run.sh`
- **THEN** второй локальный прогон использует `--optimize`, а заголовок и
  сохранённый результат называют оптимизированный вариант

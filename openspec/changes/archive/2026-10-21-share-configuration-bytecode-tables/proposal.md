# Share configuration bytecode tables

The original BUH startup reaches background capability preparation and aborts while growing the public textual worker image to2967994368bytes under the existing12GiB address-space ceiling. Its configuration programs already share name and shape tables in memory, but the current writer repeats those tables for every module. Preserve the same public textual worker transport and remove that repeated representation, rather than moving the failure from manager access to job submission.

Version the text format for an explicit reference to the first configuration module's immutable name/shape tables. Standalone programs and programs with different tables continue to carry their complete tables. The VM instruction representation, resolver, isolation and dependency boundaries do not change.

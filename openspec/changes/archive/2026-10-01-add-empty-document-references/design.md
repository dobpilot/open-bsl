# Design

The full vendor syntax helper EmptyRef294.html under objects/catalog125/catalog143/object145 specifies a zero-argument method returning DocumentRef of the owning document. object147 and UUID1613.html document the reference's UUID, metadata and empty-state methods. Preserve a native measurement in a dedicated throwaway infobase before runtime changes.

Expand the existing immutable reference implementation to the reached document kind, with distinct qualified lookup names and identity namespace. Retain one shared identity/hash/presentation/graph mechanism rather than implement a second reference model. Catalog constructors and decomposition helpers remain catalog-only. Document declarations use acquired names, not source rewriting or a guess from variable names.

Only the measured reference surface is introduced. Record reads, document object creation and filled-reference presentations without an adapter remain outside this increment and must fail explicitly if reached. Empty-reference construction is an in-memory operation. Native probe XML uses a minimal document derived from the existing platform XML structure, with fresh deterministic GUIDs and no business records.

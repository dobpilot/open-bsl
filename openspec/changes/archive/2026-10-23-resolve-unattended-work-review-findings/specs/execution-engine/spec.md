## ADDED Requirements

### Requirement: Ошибка модуля конфигурации называет модуль
Ошибка разбора, разрешения имён или компиляции, возникшая в именованном модуле каталога конфигурации при сборке движка, SHALL доходить до хоста вариантом `Error::InModule` с именем модуля и исходной ошибкой фазы внутри. Текстовое представление SHALL начинаться с имени модуля. Структурные ошибки каталога (дубль имени модуля, неизвестный импорт, цикл импортов) SHALL оставаться вариантом `Error::Configuration` без обёртки.

#### Scenario: Синтаксическая ошибка в модуле
- **WHEN** движок собирается из каталога, в одном модуле которого синтаксическая ошибка
- **THEN** сборка возвращает `Error::InModule` с именем этого модуля
- **AND** внутренняя ошибка — `Error::Parse`
- **AND** текст ошибки начинается с «модуль «<имя>»:»

#### Scenario: Структурная ошибка каталога
- **WHEN** модуль каталога импортирует неизвестный модуль
- **THEN** сборка возвращает `Error::Configuration` без обёртки `InModule`

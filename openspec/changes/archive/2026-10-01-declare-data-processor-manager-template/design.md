# Design

Use the existing manager method table and SessionFactory configuration_method_context path. Register only the reached DataProcessor manager kind, not every metadata class by analogy. The syntax helper document platform-syntax-help:syntax-context:objects/catalog125/catalog139/object141/methods/GetTemplate289.html (8.3.27.2342) specifies one required String or template metadata argument and a template value result.

The first implementation declares the documented signature and explicitly rejects actual retrieval until resource acquisition and decoding are implemented. This is an incomplete implementation boundary, not a conjectured 1C value. It follows the existing explicit unsupported common-template behavior. If the startup scenario actually calls retrieval, implement and measure resource behavior rather than returning a dummy document.

Preserve platform-first manager dispatch, source export/function priority, other metadata kinds, aliases and arity checks through existing mechanisms. No blanket acceptance of unresolved functions.

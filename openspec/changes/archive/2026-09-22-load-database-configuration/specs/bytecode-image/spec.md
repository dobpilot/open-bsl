## ADDED Requirements

### Requirement: Объявленные импорты сохраняются без статического использования

Образ SHALL сохранять каждый объявленный импорт модуля, даже если статический код не создал ни одной связи с ним. Импорт SHALL сохранять псевдоним, номер целевого модуля и признак участия экспортов цели в глобальной области. Динамический фрагмент SHALL видеть тот же именованный и глобальный импортный контекст, что и исходный модуль. Цикл в графе объявлений SHALL быть допустим; ошибкой исполнения остаётся фактическая рекурсивная инициализация модуля.

#### Scenario: Глобальный импорт используется только динамически
- **WHEN** модуль содержит `Выполнить` или `Вычислить`, обращающийся к экспорту глобального общего модуля голым именем
- **THEN** запись и чтение образа сохраняют признак глобального импорта
- **AND** динамический фрагмент связывает вызов с тем же модулем

#### Scenario: Взаимные объявления без рекурсивной инициализации
- **WHEN** два модуля ссылаются на экспортные методы друг друга, но их тела верхнего уровня не вызывают друг друга при инициализации
- **THEN** образ проходит проверку
- **AND** вызов экспортного метода исполняется

#### Scenario: Предыдущая версия
- **WHEN** загрузчик новой версии получает образ без признака глобального импорта
- **THEN** он отвергает образ по версии
- **AND** не восстанавливает видимость догадкой

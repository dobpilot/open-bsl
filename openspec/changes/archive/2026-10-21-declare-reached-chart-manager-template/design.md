# Design
Reuse the existing receiver method context and explicit unsupported-template path described by configuration-manager-template. Native control confirms qualified and own-manager Russian and English lookup, missing-template refusal and successful TextDocument retrieval from an independently exported native XML fixture.

Do not infer static arity from dynamic evaluation. The native dynamic-evaluation control accepts zero arguments and returns Undefined despite the vendor help marking the argument required. A separate direct static call is being measured before finalizing the delta and implementation.

No template result is fabricated. If the startup path reaches real retrieval, acquire and decode the actual resource using existing document components rather than returning an empty substitute.

Completed direct static native controls confirm zero arguments return Undefined both qualified and bare. The declaration therefore uses 0..1; this does not modify other manager contracts.

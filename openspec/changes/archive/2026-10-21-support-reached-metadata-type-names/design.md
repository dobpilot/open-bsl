# Design

The native control `tests/conformance/measure/1c/measure-metadata-object-type.platform.txt` confirms that a data processor metadata value matches Type("ОбъектМетаданных") and Type("MetadataObject"). Its presentation is Metadata object; the root presentation is Metadata object Configuration. Add aliases to the existing generic descriptor without changing its identity or the configuration-root descriptor. Existing lookup names remain valid.

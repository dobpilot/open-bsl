# Design
Implement the existing Session EventLogWriter trait in a small CLI module. Deliver independent events synchronously to stderr with std::io::Write and existing open_bsl::format_value for BSL values. Propagate formatting and output failures. No database event journal or transaction buffering is claimed: transactional mode fails explicitly. Inherited event-use and enabled-level methods remain unsupported. Register this writer only in the --config-db resources builder. Source and user selection behavior remain unchanged.

Stderr is a host transport choice, not inferred 1C platform behavior. The existing Session requirement already measures argument construction and rejects a missing writer. New checks exercise the BSL-to-host boundary, delivered fields and unsupported transaction mode. The private CLI copy is isolated from root sources while the root regression run is active. Its settings adapter wiring reuses the already prepared CLI patch and SDK stack. A SessionFactory probe success is not claimed as CLI acceptance; an actual configured CLI replay is required separately.

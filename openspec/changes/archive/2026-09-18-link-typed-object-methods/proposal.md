# Change: Связывать методы доказанных компонентных типов

## Why

`core_receivers` уже доказывает неизменность класса получателя, но
сохраняет только вердикт «ядровый». Поэтому даже `Новый ЗаписьJSON` теряет
конкретный тип, а каждый метод повторно проходит через
`CallObjectMethod`/`CallObjectProcedure` и мономорфный кэш VM.

## What Changes

- Конструктор компонента может объявить конкретный возвращаемый тип.
- Sema переносит этот тип через консервативный анализ перепривязок.
- Образ хранит устойчивую связь типизированного метода, а не Rust-указатель.
- Linker один раз превращает связь в `MethodDescriptor`; VM вызывает его без
  поиска имени и проверки inline cache.
- Недоказанный или полиморфный получатель остаётся открытым.

## Impact

- Меняются public Rust component ABI, bytecode representation и формат.
- Наблюдаемая BSL-семантика не меняется.
- Целевой эффект проверяется на `json_write`, `xml_parse`, `xml_write` чередующимся A/B.

## ADDED Requirements

### Requirement: Метод доказанного компонентного типа связывается до исполнения

Образ SHALL хранить устойчивую связь метода, если все перепривязки получателя
доказанно создают один конкретный тип. Связь SHALL NOT хранить адрес Rust-функции.

#### Scenario: Мономорфный компонентный получатель

- **GIVEN** переменная получает только значения одного объявленного компонентом типа
- **WHEN** компилятор формирует вызов его статического метода
- **THEN** байткод ссылается на пакет, тип и метод
- **AND** linker разрешает обработчик до первой инструкции

#### Scenario: Полиморфный или изменяемый получатель

- **WHEN** получатель может получить неизвестное значение или значения разных типов
- **THEN** компилятор сохраняет открытый вызов

#### Scenario: Загрузка образа с другим registry

- **WHEN** указанный пакет, тип или метод отсутствует либо не совместим с образом
- **THEN** связывание отвергает образ до исполнения

## ADDED Requirements

### Requirement: Межмодульная связь типизируется до исполнения

VM SHALL после проверки образа подготовить типизированную цель для
каждой инструкции межмодульного вызова, чтения и записи. Исполнение SHALL
NOT повторно классифицировать ту же запись связи.

#### Scenario: Вызов экспортной функции

- **WHEN** VM исполняет `CallImported`
- **THEN** целевой модуль, функция и набор режимов берутся из
  подготовленной записи
- **AND** готовность модуля и аргументы проверяются динамически

#### Scenario: Доступ к экспортной переменной

- **WHEN** VM исполняет `GetImportedVar` или `SetImportedVar`
- **THEN** владелец и слот берутся из типизированной записи
- **AND** alias активного кадра и состояние сессии разрешаются на каждом доступе

# Design

The catalog namespace identity and the metadata configuration object's GUID are distinct in the native CF: the retained control has catalog identity e2267f2f-daf0-49f2-b383-c9bc3ebe5df0 and root metadata GUID 26c30ece-33b5-498a-b409-a91a046ba66b. Preserve the catalog namespace and type identities. Add an optional configuration_object_id and an additive with_configuration_object_id builder, populated from the root index's acquired resource GUID. Construct the MetadataObject request target with that explicit object identity, the acquired configuration name and a new Configuration kind; do not insert a fictitious collection or object into the catalog. Missing root identity fails explicitly. Existing object targets and the request getter remain unchanged.

Root calls always delegate through DataAccess.access_right. The root adapter validates the supported right before a privileged bypass. Native 1C 8.3.27.2342 controls in own infobases establish: current denied user returns false ordinarily and true in a privileged frame; an explicit denied role remains false in both modes; an explicit user requires Administration even when it is the current user, while privileged mode bypasses this administrative gate but still evaluates that user's frozen roles. Unknown and inapplicable rights raise even in privileged mode. Non-root dispatch is outside this change.

The adapter reuses Right parsing and RoleRights.grants from open-sdbl and the session's existing AccessStore. SaveUserData and Administration are the reached supported root rights; other root rights remain explicit unsupported errors. Missing/unreadable role data never becomes a false grant or refusal. Explicit users must be present in the acquired user snapshot. No SQL is required for cached rights; unavailable role data raises rather than silently selecting another principal.

Evidence: docs/research/fixtures/configuration-access-right-complete-native-1015, including two own users, both role XML definitions, positive and negative native results, and CF-extracted role resources. Authentication passwords are empty in this disposable control only. The original databases were not modified.

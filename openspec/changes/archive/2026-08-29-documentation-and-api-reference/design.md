# Проектирование

## Документация

Текущая архитектура и справочник отделяются от планов и исследований. Старые
проекты рефакторинга переносятся в архив без редактирования их выводов. Все
ссылки в исходниках и тестах меняются вместе с путями.

## Справочник API

Генератор живёт в `bsl-cli`, потому что именно стандартная сборка CLI задаёт
набор feature-компонентов `open-bsl`. Он обходит `RuntimeRegistry` и таблицы
ядра. Имя, псевдонимы и арность не копируются в новую таблицу.

`LibraryDescriptor` уже раскрывает функции, конструкторы и типы. Для
объектных членов `ObjectMembersDescriptor` связывает тип с существующими
таблицами `MethodDescriptor` и `PropertyDescriptor`; строки и арности не
копируются. Объекты с динамическими именами помечаются отдельно: генератор не
выдаёт статическую часть за полный перечень свойств экземпляра.

Вывод без аргумента идёт в stdout. Аргумент задаёт файл; ошибка построения
движка или записи даёт ненулевой код и сообщение в stderr. Порядок разделов и
строк устойчив, чтобы снимок давал содержательный diff.

## OpenSpec

Используется стандартная схема `spec-driven`: `specs/` — текущая истина,
`changes/` — предложения и delta specs. CLI OpenSpec остаётся инструментом
разработчика вне Rust workspace.

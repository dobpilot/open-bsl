# Design

Use the existing EnumValue / EnumKind registry and its member-name table. No component object or host service is required for immutable system enum values.

The original buh source references GCM and APNS in the dormant ДанныеАутентификации function. A direct native 8.3.27.2342 control also measures FCM: display strings are GCM, APNs and FCM; the type display is DeliverableNotificationSubscriberType; English namespace aliases compare equal. The retained oracle is docs/research/fixtures/notification-subscriber-type/measure.platform.txt. The control uses the existing runner and an owned temporary infobase, not the original databases.

The Syntax Assistant also lists HPK, RMS and WNS. They are outside the reached blocker and are not included without their own controls. No push notification execution is introduced.

A separate direct native measure-bare control establishes EnumDeliverableNotificationSubscriberType for both the bare value and its type. It differs from the member type name. The existing enum metatype table carries this measured representation; no general enum metatype rule is changed.

# Решение

Перенести существующий форматтер в метод дописывания. Все позиции цифр
отсчитываются после прежнего содержимого буфера; знак, масштаб и BigInt
обрабатываются прежним алгоритмом. Внутренний сериализатор вызывает
метод после `begin_item`, без промежуточной строки числа.
Холодная ветка префикса дроби сохраняет прежнюю вспомогательную строку.
Новых алгоритмов, зависимостей и решений о поведении 1С нет.

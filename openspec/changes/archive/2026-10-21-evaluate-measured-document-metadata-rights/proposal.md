# Evaluate measured document metadata rights

## Why

The host already preserves acquired document-attribute targets, but its database adapter rejects them explicitly. Retained native controls now cover 432 Document owner, Number, Date and ordinary-attribute Read/View observations.

## What Changes

Delegate these measured targets to the reviewed SDK resolver and existing acquired role evaluator. Preserve applicability, explicit subjects, privilege ordering, current-principal identity and the existing Session denial journal path.

## Impact

The change is confined to bsl-config-db rights dispatch and tests, with independently reviewed SDK 0.9.29. No query-field policy, SQL generation, dependency or interpreter changes.

# Design

Use the existing ORM constructor declaration pattern of Boundary (new_query_boundary), not another interpreter or a source rewrite. Append a new constructor code and type descriptor without changing existing codes or type indices. Native 1C controls establish the aliases PointInTimeWithPeriodAdjustment and МоментВремениСУточнениемПериода, arity 1..3 and type display.

This is an explicit host capability boundary, not a fabricated platform value. Actual execution returns a clear unsupported-object-model error for accepted arities. No Undefined or success-shaped object is returned. The current failure is semantic compilation; whether startup eventually calls this constructor is decided by replaying the original code. If reached at runtime, implement the necessary object behavior from the retained measurements before claiming startup success.

The native corpus also measures three read-only properties, conversions and comparisons, including corrections to vendor documentation. Those behaviors are evidence, not features implemented by this declaration. Boundary and accounting-query execution remain unchanged. No platform semantic assumption is introduced by the explicit unsupported boundary.

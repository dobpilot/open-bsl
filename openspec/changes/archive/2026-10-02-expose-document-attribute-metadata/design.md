# Design

Native 8.3.27.2342 measure-document-attribute-metadata.bsl confirms ordered Count/Get/numeric indexing, case-insensitive Find, name indexing, undefined missing Find and identity of property/index access. The native missing-reference filling script already proves metadata FillValue yields the same typed identity transferred by document filling. Syntax help object1556/properties/FillFromFillingValue8052.html identifies the Russian read-only property ЗаполнятьИзДанныхЗаполнения and English FillFromFillingValue.

Reuse the existing metadata type descriptors and collection method table. Put small immutable attribute views in a dedicated module: the collection holds the acquired Arc attribute array and a value holds that same array plus its stable index. Keep existing top-level object collection behavior and identity keys unchanged. Attribute identity uses the immutable attribute-array allocation and index, separate from the owning metadata object's identity. Do not add a second metadata catalog or duplicate filling graphs.

Restore FillValue using current CallContext runtime shapes so concrete enumeration references use the receiving catalog's materializers. Require exactly one root just as document filling does. Preserve Unknown (None) versus acquired empty collections, absent filling data versus a graph containing Undefined, and false versus an unknown filling flag. Properties are read-only.

No claim is made here about acquisition of applicable common attributes or the complete MetadataObject API: those remain tracked obligations. Supported acquired attribute views must not fabricate additional members or expose tabular-section fields as document attributes. BSL Get is added to the existing metadata collection table and calls the existing index protocol; existing numeric indexing stays unchanged for object collections.

Supplementary native type probes show Metadata object for both document and attribute metadata; their types compare equal. ОбъектМетаданныхРеквизит is not a native lookup name. Keep the existing generic descriptor identity and lookup name, correcting only its type_display to the measured presentation. Existing tests do not assert the old type_display; do not change their expectations. Native Get converts numeric strings and Boolean values, whereas a nonnumeric name passed to Get fails; name indexing remains distinct. Reuse the existing enumeration index conversion helper rather than adding another numeric parser.

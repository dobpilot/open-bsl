# Spec Delta

## MODIFIED Requirements

### Requirement: Дескрипторы как источник истины

Справочник SHALL получать имена, псевдонимы, типы, методы и свойства из тех же runtime-дескрипторов, которые использует исполнение. Арность в справочник не выводится.

#### Scenario: Изменение публичного дескриптора

- **WHEN** разработчик меняет публичный runtime-дескриптор
- **THEN** сгенерированный справочник меняется без правки второй таблицы API

#### Scenario: Арность не печатается

- **WHEN** справочник сгенерирован
- **THEN** ни одна таблица не содержит колонки с числом аргументов

## ADDED Requirements

### Requirement: Описание и файл реализации

Каждая строка функции, конструктора, типа, метода и свойства SHALL содержать описание и путь к файлу реализации вида `крейт/src/файл.rs`. Генератор SHALL выводить их из исходников workspace: описание — первое предложение doc-комментария реализации или строки дескриптора, файл — место реализации. Если описания в исходниках нет, строка SHALL показывать прочерк. Номер строки в ссылку не входит.

#### Scenario: Реализация с doc-комментарием

- **WHEN** у функции, реализующей метод, есть doc-комментарий
- **THEN** строка метода показывает его первое предложение и путь к файлу этой функции

#### Scenario: Реализация без комментария

- **WHEN** ни у реализации, ни у строки дескриптора нет doc-комментария
- **THEN** строка показывает прочерк в колонке описания и путь к файлу реализации

#### Scenario: Исходники недоступны

- **WHEN** команда запущена там, где исходников workspace нет
- **THEN** она завершается с кодом 1 и сообщением об отсутствии исходников, не записывая справочник

## 3. Проверка

- [x] 3.1 `cargo fmt`, `clippy -D warnings`, rustdoc, полный workspace.
- [x] 3.2 Круговой текстовый корпус побайтово не изменился.
- [x] 3.3 Сверка JIT с интерпретатором на всём корпусе.
- [x] 3.4 Проверено по машинному коду командой
  `./benchmarks/hot-code-diff.sh 65fd3f5^`: `step` — 0xb099, 8970
  инструкций, `step_cold` — 0x55d3, 4040 инструкций; обе совпадают.
  Такты в тот вечер были неразрешимы — разброс базы до 102 % при load
  average 5, — поэтому вердикт вынесен по коду, а не по времени.

## 4. По замечаниям ревью

- [x] 4.1 Классификация представимости сведена в ОДИН исчерпывающий
  разбор без ветви-заглушки (`text::classify_const`), которым пользуются
  и проверяемое преобразование, и печать. Прежде их было две, и новый
  вариант `BslValue` обновил бы только печать.
- [x] 4.2 Тест `the_checked_conversion_and_printing_agree_on_representability`
  проверяет согласие обеих сторон на каждом значении; зубы подтверждены
  возвратом прежней ветви-заглушки.
- [x] 4.3 Документация `transient` и требование спецификации говорят
  «контрактный обход для непечатаемых программ», а не «непредставимое
  невозможно»: типы этого не обеспечивают и обеспечить не могут.
- [x] 4.4 Проверка представимых значений дополнена датой, членом
  перечисления и типом перечисления — всем, что называет сценарий.
- [x] 4.5 Сравнение машинного кода оформлено воспроизводимой командой
  `benchmarks/hot-code-diff.sh` и описано в `AGENTS.md`.

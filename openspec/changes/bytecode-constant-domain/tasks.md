## 1. Проверка невозможного состояния

- [x] 1.1 Тест: объект не преобразуется в константу байт-кода.
- [x] 1.2 Тест: тип не преобразуется в константу байт-кода.
- [x] 1.3 Тест: каждое представимое значение преобразуется и печатается.

## 2. Тип

- [x] 2.1 Ввести прозрачный тип константы с проверяемым преобразованием
  и разыменованием в `BslValue`.
- [x] 2.2 Перевести `Chunk::consts` на него.
- [x] 2.3 Перевести сборщиков: компилятор, разбор листинга, обвязки.

## 3. Проверка

- [x] 3.1 `cargo fmt`, `clippy -D warnings`, rustdoc, полный workspace.
- [x] 3.2 Круговой текстовый корпус побайтово не изменился.
- [x] 3.3 Сверка JIT с интерпретатором на всём корпусе.
- [x] 3.4 Проверено по машинному коду командой
  `./benchmarks/hot-code-diff.sh 65fd3f5^`: `step` — 0xb099, 8970
  инструкций, `step_cold` — 0x55d3, 4040 инструкций; обе совпадают.
  Такты в тот вечер были неразрешимы — разброс базы до 102 % при load
  average 5, — поэтому вердикт вынесен по коду, а не по времени.

## 4. По замечаниям ревью

- [x] 4.1 Классификация представимости сведена в ОДИН исчерпывающий
  разбор без ветви-заглушки (`text::classify_const`), которым пользуются
  и проверяемое преобразование, и печать. Прежде их было две, и новый
  вариант `BslValue` обновил бы только печать.
- [x] 4.2 Тест `the_checked_conversion_and_printing_agree_on_representability`
  проверяет согласие обеих сторон на каждом значении; зубы подтверждены
  возвратом прежней ветви-заглушки.
- [x] 4.3 Документация `transient` и требование спецификации говорят
  «контрактный обход для непечатаемых программ», а не «непредставимое
  невозможно»: типы этого не обеспечивают и обеспечить не могут.
- [x] 4.4 Проверка представимых значений дополнена датой, членом
  перечисления и типом перечисления — всем, что называет сценарий.
- [x] 4.5 Сравнение машинного кода оформлено воспроизводимой командой
  `benchmarks/hot-code-diff.sh` и описано в `AGENTS.md`.
- [x] 4.6 Скрипт сравнивает инструкции ВМЕСТЕ С ОПЕРАНДАМИ, а не одни
  мнемоники: подмена цели вызова прежде прошла бы как совпадение.
  Снимается только уникальный для сборки шум; слепая зона —
  анонимный пул констант — названа в самом скрипте и в `AGENTS.md`.
- [x] 4.7 Любой отказ сравнения даёт код возврата 1: прежде
  несравнённая функция завершалась сообщением «не изменился».
  Проверено подстановкой несуществующего символа.
- [x] 4.8 Вывод «нечего искать посредством A/B» снят: скрипт объявлен
  экраном, а не заменой замера.
- [x] 4.9 Каждый прогон работает в своём `mktemp -d`, со своим
  `CARGO_TARGET_DIR` у обеих сборок и своим worktree, всё убирается по
  `trap`. Общий `target/` не используется: параллельный агент мог
  подставить свой бинарник между сборкой и копированием.
- [x] 4.10 В сравнение добавлена длина кодировки каждой инструкции:
  один и тот же переход кодируется коротко и длинно, и одинаковый текст
  при одинаковом размере функции сам по себе раскладку не доказывал.
- [x] 4.11 `RUSTFLAGS` и `CARGO_ENCODED_RUSTFLAGS` снимаются для обеих
  сборок с явным предупреждением: любой из них перекрывает
  `-align-all-functions=5`, без которого сравнение недействительно.

# Задачи

Предпосылка: изменение `bytecode-line-table` принято и влито. Без таблицы
строк пункты 3 и 4 нечем выполнить.

## 1. Ключи

- [ ] 1.1 `--debug`, `--debug-host <адрес>`, `--debug-port <порт>` в
  разборе аргументов; `--debug` — модификатор запуска по образцу
  `--optimize`, а не команда.
- [ ] 1.2 Тест: `--debug-port` или `--debug-host` без `--debug` — ошибка
  с ненулевым кодом, а не молчаливый обычный прогон.
- [ ] 1.3 Тест: без ключей умолчания дают `127.0.0.1:4711`; занятый порт
  даёт внятный отказ, а не панику.
- [ ] 1.4 Ключи описаны в `--help` из той же таблицы, что их разбирает.

## 2. Транспорт

- [ ] 2.1 Кадрирование `Content-Length` — чтение и запись, с тестом на
  склеенные и разорванные кадры.
- [ ] 2.2 Сокет в отдельном `std::thread`, обмен строками через канал;
  ни одно BSL-значение границу потока не пересекает.
- [ ] 2.3 `serde_json` добавлен в `bsl-cli` и НЕ появляется в
  `cargo tree -p bsl-vm -e normal` и `-p open-bsl`.
- [ ] 2.4 Тест: `pause` доходит до прогона, крутящегося в цикле без
  остановок.

## 3. Крючок в VM

- [ ] 3.1 Трейт крючка объявлен в `bsl-vm`, положен в контекст прогона
  рядом с `dynamic`, зовётся из внешнего цикла.
- [ ] 3.2 Отладочный прогон непучкован и с `merge_linear = false`.
- [ ] 3.3 Тест: без отладки крючка нет и поведение не отличается от
  прежнего на всём корпусе фикстур.

## 4. Сеанс

- [ ] 4.1 Запросы: `initialize`, `attach`, `setBreakpoints`,
  `configurationDone`, `threads`, `stackTrace`, `scopes`, `variables`,
  `continue`, `next`, `stepIn`, `stepOut`, `pause`, `evaluate`,
  `disconnect`, `terminate`.
- [ ] 4.2 События: `initialized`, `stopped`, `terminated`, `exited`,
  `output`.
- [ ] 4.3 `evaluate` идёт через существующий `DynamicCompiler`, второй
  семантики выражений не заводится.
- [ ] 4.4 `Сообщить` в отладочном прогоне дублируется событием `output`,
  не переставая писать в stdout.
- [ ] 4.5 Сквозной тест: скрипт, точка останова на строке, остановка,
  чтение переменной, шаг, продолжение, завершение — без редактора,
  подставным клиентом DAP.

## 5. Ворота

- [ ] 5.1 `./benchmarks/hot-code-diff.sh <база>`: `step` и `step_cold`
  побайтово те же. Не пройдёт — крючок просочился в горячий код.
- [ ] 5.2 Альтернирующий A/B на `empty_for`, `call_overhead`,
  `pi_leibniz`: обычный прогон не подорожал. Числа записываются сюда.
- [ ] 5.3 Сверка JIT с интерпретатором на всём корпусе.
- [ ] 5.4 `cargo fmt`, `clippy -D warnings`, rustdoc, полный workspace.
- [ ] 5.5 Справочник API перегенерирован, если публичная поверхность
  изменилась, и его диф просмотрен.

# Delta: удаление `Program::module_base`

## ADDED Requirements

### Requirement: Образ не описывает размещение прогона

Образ байт-кода SHALL описывать только сам байт-код. Значения, зависящие
от конкретного запуска, — в частности, положение блока модульных
переменных в стеке — SHALL NOT быть полями образа.

#### Scenario: Модульные переменные верхнего уровня

- **WHEN** программа исполняется и её функция читает модульную
  переменную со слотом `s`
- **THEN** значение берётся из `s`-й ячейки стека вызывающего

#### Scenario: Модульные переменные фрагмента

- **WHEN** фрагмент `Выполнить`/`Вычислить` исполняется на собственном
  стеке
- **THEN** его блок модульных переменных начинается с нуля этого стека,
  как и у верхнего уровня на своём
